## 阅读约定

- $x$ 表示数据，$z$ 表示潜变量或基础噪声，$\theta,\phi$ 表示可学习参数。
- 文中“课件页”均按 PDF 的 1 起始页码计数；图片来源与页码见 [SOURCES.md](SOURCES.md)。
- 课件中的少量显然排版错误已按标准公式订正，并在相应章节注明。
