## 阅读时先留意这几处

1. **2025卷附解错配。** 实际题目在 PDF 第1至4页，之后的解答包含其他版本题目。广场舞应答最优运输，不能抄成 KL 证明；实际第5题c要求 DDPM 训练和推理。
2. **扩散记号不同。** 作业4的 $`\alpha_t`$ 是累计量，等于期中卷的 $`\bar\alpha_t`$；期中卷的 $`\alpha_t=1-\beta_t`$ 是单步量。
3. **网上答案有可核实错误。** 2024民间解析的后验精度漏乘 $`\alpha_t`$；2025笔记的 top p 定义、KV cache 总复杂度等也需要纠正，详见勘误文件。
4. **本次未发现新增独立真题。** GitHub 下载的是2024卷民间解析和2025秋笔记，不应把重复题目当成另一年试卷。

## 证明与复习顺序

先用作业1掌握 ELBO 和重参数化，再用作业2复习注意力与复杂度；作业3串起 GAN 的目标、判别器和 JS；作业4推导边缘与后验；作业5区分参考答案监督与奖励监督。最后按两年期中卷练习限时作答。

归一化流在两年往年卷中都有题，所以这里完整作答。现有 [ppt README](../../README.md) 记录 2026 教学网复核时该章标注“不讲不考”；本次未重新核查当前教学安排，往年题覆盖不等于本次考试范围。
