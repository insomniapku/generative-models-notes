# 生成模型基础全题解析

五次作业与 2024、2025 两年期中卷，共 58 个作答单元，另含 2025 卷附解中的 3 道额外题。每题都列出完整原文、数学条件、PDF 页码，再给出中文详细解析、中间计算、手算例子及易错点。这是学习解析，不是课程官方标准答案。

## 合订版分卷阅读

- [作业卷](全题解析_作业卷.md)：五次作业，28 个作答单元，涵盖 VAE、AR 与 Transformer、GAN、扩散和语言模型微调。
- [期中卷](全题解析_期中卷.md)：2024、2025 两年期中题，30 个作答单元，另附 3 道额外题，并标明 2025 PDF 的附解错配。
- [GitHub资料解析与勘误](GitHub资料_解析与勘误.md)：公开资料来源、逐题对应，以及公式和概念错误的修正。

两卷均保留完整题干与详解。也可使用[分题目录](README.md)只打开某一次作业或某一年的试卷。公式采用 GitHub 数学排版，适合直接在线阅读。

题目依据为上一级目录的原 PDF，下载来源和数值检查见[解析目录](README.md)与[核验记录](核验记录.md)。
