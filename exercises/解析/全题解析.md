### 第1题 ELBO 的推导与等号条件

**原题（PDF第1页）**

Let $`p_\theta(x,z)=p(z)p_\theta(x\mid z)`$ and let $`q_\phi(z\mid x)`$ be an approximate posterior. Derive

```math
\log p_\theta(x)\geq
\underbrace{\mathbb E_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]
-D_{\rm KL}(q_\phi(z\mid x)\Vert p(z))}_{\mathcal L(\theta,\phi;x)},
```

and identify when equality holds. You may assume common support and finite required expectations.

**详细解析**

**题意。** 用近似后验 $`q_\phi(z\mid x)`$ 推导对数边缘似然的下界，并说明何时取等号。

固定观测 $`x`$，简写 $`q=q_\phi(z\mid x)`$。利用贝叶斯公式，

```math
\begin{aligned}
D_{\rm KL}(q\Vert p_\theta(z\mid x))
&=\mathbb E_q[\log q-\log p_\theta(x,z)+\log p_\theta(x)]\\
&=\log p_\theta(x)-\mathbb E_q\!\left[\log\frac{p_\theta(x,z)}{q}\right].
\end{aligned}
```

把联合分布 $`p_\theta(x,z)=p(z)p_\theta(x\mid z)`$ 代入，得到恒等式

```math
\boxed{
\log p_\theta(x)
=\underbrace{\mathbb E_q\log p_\theta(x\mid z)-D_{\rm KL}(q\Vert p(z))}_{\mathcal L(\theta,\phi;x)}
+D_{\rm KL}(q\Vert p_\theta(z\mid x)).}
```

最后一项非负，因此 $`\log p_\theta(x)\geq\mathcal L`$。**等号当且仅当 $`q_\phi(z\mid x)=p_\theta(z\mid x)`$ 几乎处处成立**。这里需要匹配的是真实后验，而不是先验 $`p(z)`$。

也可以直接用 Jensen 不等式：

```math
\log p_\theta(x)=\log\mathbb E_q\frac{p_\theta(x,z)}{q(z\mid x)}
\geq\mathbb E_q\log\frac{p_\theta(x,z)}{q(z\mid x)}.
```

直观上，重建项鼓励潜变量保留解释 $`x`$ 的信息，先验 KL 项约束潜变量的分布；它们共同构成一个可训练的下界。最大化下界通常有助于似然学习，但不保证每一步都使真实似然增大，因为后验近似的误差也会变化。


**推导细节与进一步理解**

**从 Bayes 公式到下界，中间没有省略的步骤。** Bayes 公式先给出

```math
p_\theta(z\mid x)=\frac{p(z)p_\theta(x\mid z)}{p_\theta(x)}.
```

取对数、移项，再加减 $`\log q_\phi(z\mid x)`$，得到逐个 $`z`$ 成立的关系

```math
\begin{aligned}
\log p_\theta(x)
&=\log p_\theta(x\mid z)+\log p(z)-\log p_\theta(z\mid x)\\
&=\log p_\theta(x\mid z)
-\log\frac{q_\phi(z\mid x)}{p(z)}
+\log\frac{q_\phi(z\mid x)}{p_\theta(z\mid x)}.
\end{aligned}
```

两边在 $`q_\phi(z\mid x)`$ 下取期望。左边不依赖 $`z`$，所以期望仍为自身；右边第二、三项分别恰好是两个 KL。这解释了为什么 ELBO 里的先验 KL 带负号，而下界差距里的后验 KL 带正号。

**用一个两点例子理解“下界”。** 假设固定观测 $`x`$ 后，联合概率在两个潜变量上为 $`p(x,z=1)=0.2`$、$`p(x,z=2)=0.3`$，则 $`p(x)=0.5`$，真实后验是 $`(0.4,0.6)`$。若近似后验取 $`(0.5,0.5)`$，

```math
\mathrm{ELBO}=\tfrac12\log(0.2/0.5)+\tfrac12\log(0.3/0.5)
\approx-0.71356<\log0.5\approx-0.69315.
```

若改为真实后验 $`(0.4,0.6)`$，两个联合概率除以后验都等于 $`0.5`$，Jensen 中的随机量变为常数，ELBO 就等于 $`\log0.5`$。因此“后验近似越准确，下界越紧”指的是固定生成模型和固定观测时，后验 KL 越小。

**为什么不直接最大化边缘似然。** $`p(z)`$ 通常很简单，但 $`\int p(z)p_\theta(x\mid z)dz`$ 穿过了非线性解码器，积分及真实后验往往难算。ELBO 引入可采样、可计算的 $`q_\phi`$，将训练变成重建期望加可处理的正则项，而不是声称真实似然不存在或不能定义。

### 第2题 一般多元高斯之间的 KL 散度

**原题（PDF第1页）**

For $`d`$-dimensional Gaussians $`q(z)=\mathcal N(\mu_q,\Sigma_q)`$ and $`p(z)=\mathcal N(\mu_p,\Sigma_p)`$ with positive definite covariance matrices, derive the closed form of $`D_{\rm KL}(q\Vert p)`$.

**详细解析**

**题意。** $`q=\mathcal N(\mu_q,\Sigma_q)`$，$`p=\mathcal N(\mu_p,\Sigma_p)`$，协方差正定。求 $`D_{\rm KL}(q\Vert p)`$。

从定义出发：

```math
\begin{aligned}
\log\frac{q(z)}{p(z)}
=\frac12\bigg[&\log\frac{\det\Sigma_p}{\det\Sigma_q}
-(z-\mu_q)^\top\Sigma_q^{-1}(z-\mu_q)\\
&+(z-\mu_p)^\top\Sigma_p^{-1}(z-\mu_p)\bigg].
\end{aligned}
```

令 $`u=z-\mu_q`$、$`\Delta=\mu_q-\mu_p`$。因为 $`\mathbb E_qu=0`$、$`\mathbb E_quu^\top=\Sigma_q`$，对任意固定矩阵 $`A`$ 有

```math
\mathbb E_q[u^\top Au]=\mathrm{tr}(A\Sigma_q).
```

于是

```math
\mathbb E_q[(z-\mu_q)^\top\Sigma_q^{-1}(z-\mu_q)]=d,
```

```math
\mathbb E_q[(z-\mu_p)^\top\Sigma_p^{-1}(z-\mu_p)]
=\mathrm{tr}(\Sigma_p^{-1}\Sigma_q)+\Delta^\top\Sigma_p^{-1}\Delta.
```

代回即得

```math
\boxed{
D_{\rm KL}(q\Vert p)=\frac12\left[
\mathrm{tr}(\Sigma_p^{-1}\Sigma_q)
+(\mu_p-\mu_q)^\top\Sigma_p^{-1}(\mu_p-\mu_q)
-d+\log\frac{\det\Sigma_p}{\det\Sigma_q}\right].}
```

常见特例 $`p=\mathcal N(0,I)`$，$`q=\mathcal N(\mu,\mathrm{diag}(e^r))`$：

```math
\boxed{D_{\rm KL}(q\Vert p)=\frac12\sum_{i=1}^d(e^{r_i}+\mu_i^2-1-r_i).}
```

**易错点。** KL 的方向决定使用谁的逆协方差；$`D_{\rm KL}(q\Vert p)`$ 中是 $`\Sigma_p^{-1}`$。若 $`p=q`$，答案应恰为 0，可用来检查符号。


**推导细节与进一步理解**

**把高斯密度的对数真正写开。** 两个高斯都含有 $`-\frac d2\log(2\pi)`$，做差后这一项抵消。剩下的行列式项来自归一化系数，二次型项来自指数；因此可以在求期望前就判断对数行列式的方向是 $`\log|\Sigma_p|-\log|\Sigma_q|`$。

二次型期望公式也可逐坐标推导：

```math
\mathbb E[u^\top Au]
=\sum_{i,j}A_{ij}\mathbb E[u_iu_j]
=\sum_{i,j}A_{ij}(\Sigma_q)_{ij}
=\mathrm{tr}(A\Sigma_q),
```

这里用到了协方差矩阵的对称性。再将 $`z-\mu_p=u+\Delta`$ 展开：

```math
(u+\Delta)^\top\Sigma_p^{-1}(u+\Delta)
=u^\top\Sigma_p^{-1}u+2\Delta^\top\Sigma_p^{-1}u
+\Delta^\top\Sigma_p^{-1}\Delta.
```

中间交叉项的期望为零，是因为 $`\mathbb E u=0`$，而不是因为每个样本上 $`u`$ 都等于零。

**检查一维特例。** 公式应退化为

```math
D_{\rm KL}(\mathcal N(\mu_q,\sigma_q^2)\Vert\mathcal N(\mu_p,\sigma_p^2))
=\frac12\left[\frac{\sigma_q^2+(\mu_q-\mu_p)^2}{\sigma_p^2}
-1+\log\frac{\sigma_p^2}{\sigma_q^2}\right].
```

若方差相同而均值不同，KL 就是均值差平方除以 $`2\sigma^2`$；若均值相同而方差比例为 $`r=\sigma_q^2/\sigma_p^2`$，KL 为 $`(r-1-\log r)/2`$，由 $`\log r\le r-1`$ 可确认非负。正定性保证逆矩阵和对数行列式存在，不能把这套普通密度公式不加说明地用于退化高斯。

### 第3题 输出对数方差时的重参数化梯度

**原题（PDF第1页）**

An encoder outputs $`\mu,r\in\mathbb R^d`$, where $`r_i=\log\sigma_i^2`$. Define

```math
F(\mu,r)=\mathbb E_{z\sim\mathcal N(\mu,\mathrm{diag}(e^r))}[f(z)].
```

Assume that $`f`$ is differentiable, and that differentiation and expectation may be interchanged. Using parameter-independent noise $`\epsilon\sim\mathcal N(0,I)`$, derive a reparameterized expression for $`\nabla_{(\mu,r)}F`$.

**详细解析**

**题意。** 编码器输出 $`\mu,r`$，其中 $`r_i=\log\sigma_i^2`$，求
$`F(\mu,r)=\mathbb E_{z\sim\mathcal N(\mu,\mathrm{diag}(e^r))}f(z)`$ 对两组参数的梯度。

取与参数无关的 $`\epsilon\sim\mathcal N(0,I)`$，定义

```math
\sigma=e^{r/2},\qquad z=\mu+e^{r/2}\odot\epsilon.
```

注意标准差是 $`e^{r/2}`$，不能写成 $`e^r`$。于是

```math
F(\mu,r)=\mathbb E_\epsilon f(\mu+e^{r/2}\odot\epsilon).
```

固定一次噪声后，$`\partial z_i/\partial\mu_j=\mathbf1_{i=j}`$，而
$`\partial z_i/\partial r_j=\tfrac12e^{r_i/2}\epsilon_i\mathbf1_{i=j}`$。在题目允许交换微分与期望的条件下，

```math
\boxed{\nabla_\mu F=\mathbb E_\epsilon[\nabla_zf(z)],\qquad
\nabla_r F=\frac12\mathbb E_\epsilon[\nabla_zf(z)\odot e^{r/2}\odot\epsilon].}
```

若使用 $`K`$ 个独立噪声样本，以样本平均替换期望就得到无偏的路径梯度估计。对上游编码器参数 $`\phi`$ 再使用链式法则：

```math
\nabla_\phi F=J_\mu(\phi)^\top\nabla_\mu F+J_r(\phi)^\top\nabla_r F.
```

这里题设的 $`f`$ 没有显式依赖 $`\mu,r`$；若它还显式依赖参数，需要额外加入对应的直接偏导项。重参数化解决的是如何对含采样的期望求梯度，而不是消除随机性。


**推导细节与进一步理解**

**为什么梯度可以通过采样。** 原表达式的积分权重由 $`\mu,r`$ 决定；换成标准高斯 $`\epsilon`$ 后，积分权重固定，参数只出现在 $`z(\mu,r,\epsilon)`$ 这个确定变换中。对一次固定噪声做微小参数扰动时，噪声不重抽，而样本位置会随参数连续移动，这就是路径梯度。

逐坐标链式法则为

```math
\frac{\partial}{\partial\mu_j}f(z)=\sum_i\frac{\partial f}{\partial z_i}\frac{\partial z_i}{\partial\mu_j}
=\frac{\partial f}{\partial z_j},
```

```math
\frac{\partial}{\partial r_j}f(z)=\sum_i\frac{\partial f}{\partial z_i}\frac{\partial z_i}{\partial r_j}
=\frac{\partial f}{\partial z_j}\cdot\frac12e^{r_j/2}\epsilon_j.
```

**用能手算的函数检查 $`1/2`$。** 一维取 $`f(z)=z^2`$，则 $`F=\mu^2+e^r`$，所以正确梯度是 $`\partial_\mu F=2\mu`$、$`\partial_rF=e^r`$。路径公式给出

```math
\mathbb E[2z]=2\mu,\qquad
\mathbb E[2z\cdot\tfrac12e^{r/2}\epsilon]
=\mu e^{r/2}\mathbb E\epsilon+e^r\mathbb E\epsilon^2=e^r.
```

如果把 $`r`$ 错当成 log standard deviation，就会漏掉或多出因子 2。实际反向传播时，编码器的 $`\mu,r`$ 两路都必须保留计算图；参数无关的是 $`\epsilon`$，不是变换后的 $`z`$。

### 第4题 Gumbel Max 与 Gumbel Softmax

**原题（PDF第1页）**

Paper: Eric Jang, Shixiang Gu, and Ben Poole. *Categorical Reparameterization with Gumbel-Softmax*. ICLR 2017. Citation 9500+.

Explain what is Gumbel-Max trick and prove it. Explain when and how to use Gumbel-Softmax trick.

**详细解析**

#### Gumbel Max 的结论

设类别权重 $`w_i>0`$，概率 $`\pi_i=w_i/\sum_jw_j`$，且 $`g_i`$ 独立服从标准 Gumbel 分布，累积分布函数为 $`F(g)=\exp(-e^{-g})`$。则

```math
\boxed{k=\arg\max_i(\log w_i+g_i)\quad\Longrightarrow\quad\Pr(k=i)=\pi_i.}
```

可以用 $`u_i\sim\mathrm{Uniform}(0,1)`$ 和 $`g_i=-\log(-\log u_i)`$ 生成 Gumbel 噪声。使用 $`\log\pi_i`$ 或未归一化的 logit 都可以，因为共同的加法常数不影响最大值。

#### 用指数竞赛证明

令 $`E_i=e^{-g_i}=-\log u_i`$，则 $`E_i\sim\mathrm{Exp}(1)`$。再令 $`T_i=E_i/w_i`$，则 $`T_i\sim\mathrm{Exp}(w_i)`$ 且独立。注意

```math
\log w_i+g_i=-\log(E_i/w_i)=-\log T_i.
```

因此取最大值等价于取 $`T_i`$ 的最小值。独立连续分布的平局概率为零，故

```math
\begin{aligned}
\Pr(k=i)
&=\int_0^\infty \underbrace{w_i e^{-w_it}}_{T_i\text{ 的密度}}
\prod_{j\ne i}\underbrace{e^{-w_jt}}_{\Pr(T_j>t)}\,dt\\
&=w_i\int_0^\infty e^{-(\sum_jw_j)t}\,dt
=\frac{w_i}{\sum_jw_j}.
\end{aligned}
```

零概率类别可删除，或把其 logit 视为 $`-\infty`$。

#### 何时以及怎样使用 Gumbel Softmax

神经网络需要从类别分布采样、并让梯度通过该离散选择时，可把不可导的 one hot 最大值选择替换为温度为 $`\tau>0`$ 的连续向量：

```math
\boxed{y_i=\frac{\exp((\log w_i+g_i)/\tau)}{\sum_j\exp((\log w_j+g_j)/\tau)}.}
```

对 logit $`a_j=\log w_j`$，固定噪声后有

```math
\frac{\partial y_i}{\partial a_j}=\frac1\tau y_i(\mathbf1_{i=j}-y_j).
```

训练时先采样 Gumbel 噪声，再把 $`y`$ 输入后续网络，按普通反向传播优化。$`\tau\to0^+`$ 时 $`y`$ 几乎必然收敛到 Gumbel Max 的 one hot 样本；$`\tau\to\infty`$ 时趋于均匀向量。有限温度优化的是连续松弛目标，其梯度通常不是原离散目标梯度的无偏估计。

需要前向严格离散时，可用直通估计：前向取 $`y_{\rm hard}=\mathrm{onehot}(\arg\max_i y_i)`$，反向使用 $`y`$ 的导数，实现为 $`y_{\rm hard}-\mathrm{stopgrad}(y)+y`$。它同样是有偏估计。过低温度使输出更接近离散样本，也可能使梯度不稳定，实践中需权衡。

论文来源：[Jang 等，ICLR 2017，第 2 节](https://arxiv.org/html/1611.01144v5#S2)。上面的指数竞赛展开给出了题目所需的采样正确性证明。

**推导细节与进一步理解**

**为什么要给 log 概率加噪声。** 直接选择概率最大的类别只会得到众数，不会按整个分布抽样。Gumbel Max 让每个类别独立竞争，且竞争获胜率恰好与 $`w_i`$ 成正比。若用网络 logits $`a_i`$，取 $`w_i=e^{a_i}`$，便可直接计算 $`\arg\max_i(a_i+g_i)`$，不用先算 softmax；这有利于数值稳定。

指数竞赛里用到的分布变换可补充为：对 $`t\ge0`$，

```math
\Pr(E_i>t)=\Pr(-\log U_i>t)=\Pr(U_i<e^{-t})=e^{-t},
```

所以 $`E_i`$ 的确是率为 1 的指数变量；同理 $`\Pr(T_i>t)=e^{-w_it}`$。获胜概率积分中“自己的密度乘其他人的生存概率”，就是要求自己在 $`t`$ 时到达、其他所有类别都比 $`t`$ 晚。

**Gumbel Softmax 的梯度并没有穿过 argmax。** 它把离散选择换成概率单纯形内部的向量，后续网络因而接收连续值。对同一个 Gumbel 样本，温度逐渐减小时最大分量占据的比例越来越大；由于连续噪声下最大值几乎必然唯一，极限才是 one hot。温度很小时，大部分样本已经饱和，少数接近平局的样本又可能有较大的 $`1/\tau`$ 因子，所以不能简单认为“温度越小梯度越好”。

**直通估计的前后向分别是什么。** 写 $`y_{\rm ST}=y_{\rm hard}-\mathrm{stopgrad}(y)+y`$：前向两项 $`-y+y`$ 抵消，实际送入后续网络的是 $`y_{\rm hard}`$；反向时 stop gradient 的导数为零，$`y_{\rm hard}`$ 也不通过 argmax 求导，只留下连续 $`y`$ 的导数。因此它是一种人为设计的替代梯度，不能把“能反传”误说成“等于原离散目标的精确梯度”。

### 第1题 自回归 Transformer 的因果掩码

**原题（PDF第1页）**

In an autoregressive language model, position $`i`$ uses tokens $`x_1,\ldots,x_i`$ to predict $`x_{i+1}`$. Consider the unmasked attention operation

```math
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt d}\right)V,
\qquad Q,K,V\in\mathbb R^{n\times d},
```

where softmax is applied row-wise.

#### 第1题a 无掩码注意力为什么不符合自回归建模

**原题（PDF第1页）**

(a) Explain why unmasked attention operation fails in autoregressive modeling.

**详细解析**

自回归分解要求

```math
p(x_{1:n})=\prod_{i=1}^n p(x_i\mid x_{1:i-1}).
```

训练时整段序列都在内存中。若第 $`i`$ 行注意力可以读取 $`j>i`$ 的 $`K_j,V_j`$，其输出就可能包含 $`x_{i+1}`$，甚至更远处的信息。它在预测 $`x_{i+1}`$ 时看到了答案，造成未来信息泄漏；推理时这些未来 token 尚未生成，训练和推理的条件不一致。


**推导细节与进一步理解**

**一个具体的泄漏例子。** 训练序列是“我／喜欢／数学”，位置 1 用“我”预测“喜欢”。如果第 1 行能关注第 2 位，那么第 2 位的值向量已经由“喜欢”的嵌入计算得到，模型可以把目标信息直接抄回第 1 位。这样的训练损失再低，也不能说明模型学会了仅根据“我”预测下一词。

并行训练本身没有问题：所有真实 token 可以一起放进张量，但计算图必须保证位置 $`i`$ 的输出只依赖 $`x_{1:i}`$。推理时模型手里也恰好只有这个前缀，所以因果性要求是对**信息依赖**的要求，而不是要求训练程序真的一词一词地运行。

#### 第1题b 怎样应用掩码以及为什么有效

**原题（PDF第1页）**

(b) Explain how the causal mask is applied and why it prevents attention to future tokens.

**详细解析**

在 softmax **之前**加矩阵 $`M`$：

```math
M_{ij}=\begin{cases}0,&j\leq i,\\-\infty,&j>i,\end{cases}\qquad
O=\mathrm{softmax}_{\rm row}\!\left(\frac{QK^\top}{\sqrt d}+M\right)V.
```

因为 $`e^{-\infty}=0`$，未来位置的权重恰为 0；对合法位置重新归一化后，

```math
O_i=\sum_{j\leq i}\frac{e^{q_i^\top k_j/\sqrt d}}{\sum_{r\leq i}e^{q_i^\top k_r/\sqrt d}}v_j.
```

四个位置的掩码是

```math
M=\begin{pmatrix}
0&-\infty&-\infty&-\infty\\
0&0&-\infty&-\infty\\
0&0&0&-\infty\\
0&0&0&0
\end{pmatrix}.
```

每一层都使用此掩码，逐 token 的 FFN、LayerNorm 和残差也不跨位置混入未来信息，于是可按层归纳证明第 $`i`$ 位仅依赖 $`x_{1:i}`$。因果掩码和 padding 掩码解决不同问题，需要时应同时使用。仅在 softmax 后乘零而不重新归一化，不等于上述标准注意力。


**推导细节与进一步理解**

**逐步观察 softmax。** 先设分数为 $`s_{ij}`$，加掩码后分子变为 $`e^{s_{ij}+M_{ij}}`$。合法位置乘 $`e^0=1`$，未来位置乘 $`e^{-\infty}=0`$；分母则只剩合法位置分子的和。这样未来位置既不能贡献值向量，也不能通过分母改变合法位置的相对归一化。

**为什么对角线要保留。** 本题是输入到 $`x_i`$、预测 $`x_{i+1}`$，所以允许 $`j=i`$。若另一种数据对齐是第 $`i`$ 位直接预测输入中的 $`x_i`$，必须相应移位或使用严格下三角掩码，不能不检查输入目标对齐方式就照抄掩码。

**为什么不能只屏蔽最后一层。** 如果较早层的第 $`j`$ 个隐藏向量已经读取未来信息，后层即使只看过去位置，也可能从这些被污染的向量间接取得未来内容。必须从输入开始保证每一层的依赖都合法。实现中用足够小的有限数近似 $`-\infty`$ 时还要留意数据类型；此外，不应制造整行全为 $`-\infty`$ 的有效查询，否则 softmax 可能出现未定义值。

### 第2题 自注意力计算与复杂度

**原题（PDF第1页）**

Let $`X\in\mathbb R^{n\times d}`$ be a sequence of $`n`$ token representations. Consider a single-head self-attention layer with projection matrices $`W_Q,W_K,W_V\in\mathbb R^{d\times d}`$. Ignore biases and the output projection.

#### 第2题a 公式与维度

**原题（PDF第1页）**

(a) Write down the computation of $`Q,K,V`$ and the scaled dot-product attention output. Specify the dimension of each intermediate matrix and the axis along which softmax is applied.

**详细解析**

给定 $`X\in\mathbb R^{n\times d}`$，$`W_Q,W_K,W_V\in\mathbb R^{d\times d}`$：

```math
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,
```

```math
S=\frac{QK^\top}{\sqrt d},\qquad A=\mathrm{softmax}_{\rm row}(S),\qquad O=AV.
```

| 矩阵 | 维度 | 意义 |
|---|---|---|
| $`Q,K,V`$ | $`n\times d`$ | 每个位置的查询、键、值 |
| $`S`$ | $`n\times n`$ | 行 $`i`$ 查询与列 $`j`$ 键的相似度 |
| $`A`$ | $`n\times n`$ | 每行沿键位置 $`j`$ 做 softmax，行和为 1 |
| $`O`$ | $`n\times d`$ | 对值向量的加权求和 |

缩放 $`1/\sqrt d`$ 可控制点积随维度增长的典型幅度，减少 softmax 过度饱和。


**推导细节与进一步理解**

**每一行、每一列究竟代表什么。** $`Q_i`$ 是位置 $`i`$ 提出的查询；$`K_j`$ 负责说明位置 $`j`$ 有什么可匹配的特征；$`V_j`$ 是匹配后真正传递的信息。$`QK^\top`$ 的 $`(i,j)`$ 项因此一定是 $`q_i^\top k_j`$。若把 softmax 错做成按列归一化，就会变成“所有查询如何分配到同一个键”，不再是每个查询从所有键里汇总信息。

可按矩阵乘法检查输出：$`A_{n\times n}V_{n\times d}`$ 的第 $`i`$ 行是 $`\sum_ja_{ij}V_j`$，仍为 $`d`$ 维。注意力改变了每个位置包含的信息，不要求改变序列长度或隐藏维数。

**缩放的方差解释。** 若初始化时查询与键各坐标近似独立、零均值、方差 1，则每个乘积 $`q_\ell k_\ell`$ 的均值为 0、方差为 1，点积的方差是 $`d`$。除以 $`\sqrt d`$ 后方差回到 1 的量级。这里是帮助理解初始化的近似，不要求训练后的坐标始终独立或精确服从高斯。

#### 第2题b 时间与内存复杂度

**原题（PDF第1页）**

(b) Analyze the time complexity in terms of $`n`$ and $`d`$, distinguishing the projections from the attention computation. What is the memory complexity of explicitly storing the attention matrix?

**详细解析**

| 操作 | 时间复杂度 |
|---|---|
| 三次投影 $`XW_Q,XW_K,XW_V`$ | $`O(nd^2)`$ |
| 分数 $`QK^\top`$ | $`O(n^2d)`$ |
| softmax | $`O(n^2)`$ |
| 加权求和 $`AV`$ | $`O(n^2d)`$ |

因此总时间为 **$`O(nd^2+n^2d)`$**。只有在相应项占优时才能简写成 $`O(n^2d)`$，不能一概假设 $`n\gg d`$。显式存储注意力矩阵占 **$`O(n^2)`$** 内存；连同 $`Q,K,V,O`$，激活内存为 $`O(n^2+nd)`$，不计参数和优化器状态。固定层数、固定总维度的多头注意力保持相同主阶；若逐头存注意力，相关存储另有头数因子。


**推导细节与进一步理解**

**把 FLOPs 的来源数出来。** 一个 $`n\times d`$ 矩阵与 $`d\times d`$ 矩阵相乘，有 $`nd`$ 个输出，每个输出累积 $`d`$ 项，所以是 $`O(nd^2)`$。而注意力有 $`n^2`$ 对查询与键，每对做一次长度 $`d`$ 的点积，所以是 $`O(n^2d)`$；之后 $`AV`$ 有 $`nd`$ 个输出，每个累积 $`n`$ 项，也得到 $`O(n^2d)`$。

三次投影和两次注意力矩阵乘法的乘加次数量级可写为 $`3nd^2+2n^2d`$，未计常数倍的乘法与加法定义差异。当 $`n`$ 远小于 $`d`$ 时，投影项可能占优；当 $`n`$ 很大时，二次注意力项逐渐成为主要负担。

**内存的直观数量。** 单头长度 $`n=4096`$ 的注意力矩阵有 $`4096^2`$ 个元素，float32 存储约需 64 MiB，仅这一个矩阵就已经很大。训练还可能保存分数、概率和反向传播中间量，所以实际开销更高。题目只问“显式注意力矩阵”的内存时，回答 $`O(n^2)`$ 即可，不应把模型权重的 $`O(d^2)`$ 混入这一项。

### 第3题 RoPE 的相对位置性质

**原题（PDF第1页）**

Consider the standard, unscaled RoPE implementation with head dimension $`d=2h`$ and a fixed base $`b>1`$ (e.g., $`b=10000`$). Let $`\theta=(b^{-2\ell/d})_{\ell=0}^{h-1}\in\mathbb R^h`$. For one token at position $`t`$, split $`x\in\mathbb R^d`$ into its first and second halves $`x^{(1)},x^{(2)}\in\mathbb R^h`$ and define

```math
x=\begin{pmatrix}x^{(1)}\\x^{(2)}\end{pmatrix},\qquad
\mathrm{rotate\_half}(x)=\begin{pmatrix}-x^{(2)}\\x^{(1)}\end{pmatrix},\qquad
e_t=\begin{pmatrix}t\theta\\t\theta\end{pmatrix}.
```

The implementation applies RoPE to queries and keys using

```math
f(x,t)=x\odot\cos(e_t)+\mathrm{rotate\_half}(x)\odot\sin(e_t),
```

where $`\odot`$ denotes elementwise multiplication and sine and cosine are applied elementwise. For arbitrary query and key vectors $`q_i,k_j\in\mathbb R^d`$ at positions $`i`$ and $`j`$, prove in exact arithmetic that

```math
f(q_i,i)^\top f(k_j,j)=q_i^\top M(i-j)k_j,
```

where $`M(\delta)\in\mathbb R^{d\times d}`$ is independent of $`q_i,k_j`$ and depends on the positions only through $`\delta=i-j`$. Derive the explicit form of $`M(\delta)`$.

**详细解析**

**题意。** 使用题目指定的前半后半配对布局，而非相邻元素配对，证明旋转后的点积仅通过位置差依赖 $`i,j`$，并求 $`M(i-j)`$。

令 $`d=2h`$，$`\theta_\ell=b^{-2\ell/d}`$，并记

```math
C_t=\mathrm{diag}(\cos(t\theta_0),\ldots,\cos(t\theta_{h-1})),\quad
S_t=\mathrm{diag}(\sin(t\theta_0),\ldots,\sin(t\theta_{h-1})).
```

由题目的 $`\mathrm{rotate\_half}`$ 定义，

```math
f(x,t)=R(t)x,\qquad
R(t)=\begin{pmatrix}C_t&-S_t\\S_t&C_t\end{pmatrix}.
```

每一对 $`(x_\ell,x_{\ell+h})`$ 都是二维旋转，因此 $`R(t)^\top=R(-t)`$。直接用三角和差公式可验证

```math
R(s)R(t)=R(s+t).
```

于是

```math
f(q_i,i)^\top f(k_j,j)=q_i^\top R(i)^\top R(j)k_j
=q_i^\top R(j-i)k_j.
```

题目把位置差定义成 $`\delta=i-j`$，所以答案是

```math
\boxed{M(\delta)=R(-\delta)=
\begin{pmatrix}
C_\delta&S_\delta\\
-S_\delta&C_\delta
\end{pmatrix}.}
```

显式展开为

```math
\sum_{\ell=0}^{h-1}\left[
(q_{i,\ell}k_{j,\ell}+q_{i,\ell+h}k_{j,\ell+h})\cos(\delta\theta_\ell)
+(q_{i,\ell}k_{j,\ell+h}-q_{i,\ell+h}k_{j,\ell})\sin(\delta\theta_\ell)
\right].
```

**易错点。** $`M(i-j)`$ 是 $`R(j-i)`$；直接把 $`M(\delta)`$ 写成 $`R(\delta)`$ 会把正弦项符号弄反。这里只证明位置运算的显式依赖是相对位置；$`q_i,k_j`$ 本身仍可包含内容和上下文信息。精确算术下恒等式成立，浮点实现允许舍入差异。


**推导细节与进一步理解**

**把矩阵乘法中的符号也展开。** 由块矩阵相乘，

```math
R(i)^\top R(j)=
\begin{pmatrix}
C_iC_j+S_iS_j&-C_iS_j+S_iC_j\\
-S_iC_j+C_iS_j&S_iS_j+C_iC_j
\end{pmatrix}.
```

这些矩阵都是同一组坐标上的对角矩阵，因此彼此可交换。令 $`\delta=i-j`$，余弦差角公式给出左上、右下块 $`C_\delta`$，正弦差角公式给出右上块 $`S_\delta`$、左下块 $`-S_\delta`$。这就直接得到前面的 $`M(\delta)`$，无需仅凭记忆判断旋转方向。

**最小例子检查正负号。** 取 $`d=2`$，频率 $`\theta_0=1`$，$`q=(1,0)^\top`$、$`k=(0,1)^\top`$，位置 $`i=1,j=0`$。旋转后 $`f(q,1)=(\cos1,\sin1)^\top`$、$`f(k,0)=(0,1)^\top`$，点积为 $`\sin1`$。因此 $`M(1)`$ 的右上角必须是 $`+\sin1`$，若写成负号就与直接计算矛盾。

**为什么题目强调前后两半。** 这里配对的是第 $`\ell`$ 与第 $`\ell+h`$ 个坐标。另一类实现配对相邻坐标，在经过一个固定坐标置换后可以表达相同的二维旋转结构，但直接写出的 $`d\times d`$ 矩阵布局不同。本题必须按指定的 rotate half 实现给出答案。

### 第4题 FlashAttention 的原理

**原题（PDF第1页）**

Paper: Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, and Christopher Ré. *FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness*. NeurIPS 2022.

Explain the main idea of FlashAttention and why it can compute exact attention faster and with less memory than a standard implementation.

**详细解析**

标准实现把 $`n\times n`$ 分数和概率矩阵写入 GPU 显存，再读回计算输出。FlashAttention 将 $`Q,K,V`$ 分块放入片上 SRAM，融合局部点积、softmax 与加权求和，并在线合并归一化统计量，避免在显存中存完整注意力矩阵。反向传播按块重算所需概率，以计算换取更少的内存访问。[原论文第 3 节](https://arxiv.org/html/2205.14135v2#S3)

在线 softmax 为什么仍精确，可以用一行分数解释。设当前已处理的最大值为 $`m`$，保存

```math
\ell=\sum_{j\in\text{已处理}}e^{s_j-m},\qquad
u=\sum_{j\in\text{已处理}}e^{s_j-m}v_j.
```

新分块的分数为 $`s_j`$，令

```math
m'=\max(m,\max_{j\in\text{新块}}s_j).
```

合并规则是

```math
\ell'=e^{m-m'}\ell+\sum_{j\in\text{新块}}e^{s_j-m'},
```

```math
u'=e^{m-m'}u+\sum_{j\in\text{新块}}e^{s_j-m'}v_j.
```

所有块处理完，输出 $`u/\ell`$，正好是完整 softmax 的加权和。这是对求和与归一化的重排。

因此，稠密注意力的算术主阶仍为 $`O(n^2d)`$；额外注意力存储随序列长度线性增长，且显存与 SRAM 之间的数据传输显著减少。实际提速来自访存与融合计算。这里的“精确”指计算同一个稠密注意力函数，浮点运算顺序改变不保证逐比特一致；稀疏注意力是另外的扩展。

**推导细节与进一步理解**

**在线归一化的一个算例。** 一行注意力分数取 $`(0,\log2,\log3)`$，对应标量值为 $`(10,20,30)`$。直接 softmax 得权重 $`(1,2,3)/6`$，输出是 $`140/6`$。先处理前两项，保存 $`m=\log2`$、$`\ell=1/2+1=3/2`$、$`u=10/2+20=25`$。第三项到来后最大值变为 $`m'=\log3`$，旧累积量乘 $`e^{m-m'}=2/3`$，于是

```math
\ell'=\frac23\cdot\frac32+1=2,\qquad
u'=\frac23\cdot25+30=\frac{140}3,\qquad
\frac{u'}{\ell'}=\frac{140}6.
```

可见不需要保留此前每一个概率，只要保存最大值、归一化和、加权和，就能合并任意数量的块。最大值平移还防止直接指数运算溢出。

**“多算一点反而更快”的原因。** 标准实现通常先把大矩阵写到高带宽显存，再从显存读出。FlashAttention 把适合当前块的数据留在更快的片上存储，并在反向时按需要重算部分注意力。这可能增加部分算术操作，却节省大量昂贵的数据搬运。在访存是瓶颈时，总运行时间因此下降。

**完整答案应同时交代三点。** 它保持所有允许的查询与键交互；通过分块和在线 softmax 避免完整中间矩阵；通过融合与重计算减少显存读写。不能只写“用了更少内存”，也不能写成“把稠密注意力的 $`n^2`$ 次配对变成了 $`n`$ 次”。

### 第1题 GAN 的极小极大博弈

**原题（PDF第1页）**

Let $`z\sim p_z`$ and let $`G_\theta(z)`$ induce the generator distribution $`p_g`$. Let $`p_{\rm data}`$ be the real data distribution, and let $`D(x)\in[0,1]`$ estimate the probability that $`x`$ is real. Assume that $`p_{\rm data}`$ and $`p_g`$ admit densities with respect to a common reference measure, and use the convention $`0\log0=0`$.

#### 第1题a 完整目标与双方任务

**原题（PDF第1页）**

(a) Write down the complete minimax objective $`\min_G\max_D V(D,G)`$ for the original GAN. Explain the goals of the generator and the discriminator.

**详细解析**

```math
\boxed{\min_G\max_D V(D,G)
=\mathbb E_{x\sim p_{\rm data}}\log D(x)
+\mathbb E_{z\sim p_z}\log(1-D(G(z))).}
```

判别器最大化这个目标，让真实样本的 $`D(x)`$ 接近 1、生成样本的 $`D(G(z))`$ 接近 0。生成器最小化目标中与自己有关的第二项，让生成样本更容易被判为真。训练一般交替更新两者；不是让两者同时最小化同一个 $`V`$。


**推导细节与进一步理解**

**为什么一边最大化、一边最小化。** 把真实样本标签设为 1、生成样本标签设为 0，判别器的二元交叉熵损失是 $`L_D=-V(D,G)`$。最小化这个分类损失等价于最大化 $`V`$。固定判别器之后，第一项只包含真实数据和判别器，不含生成器参数，因此生成器真正优化的只有第二项。

在一个大小为 $`m`$ 的 minibatch 上，可以写成

```math
L_D=-\frac1m\sum_{i=1}^m\left[\log D(x_i)+\log(1-D(G(z_i)))\right],
\qquad
L_G^{\rm sat}=\frac1m\sum_{i=1}^m\log(1-D(G(z_i))).
```

判别器更新时，生成样本应当对生成器停止梯度；生成器更新时，则固定判别器参数，但继续保留“生成图像到判别器输出”的导数。二者的冻结位置不同，是对抗训练实现里常见的混淆点。

目标比较的是分布而非单个样本配对：标准 GAN 没有要求某个噪声 $`z_i`$ 必须重建某张指定的 $`x_i`$。因此不能把生成器的目标误写成逐样本重建误差。

#### 第1题b 最优判别器

**原题（PDF第1页）**

(b) For a fixed generator $`G`$, prove that an optimal discriminator is

```math
D^*(x)=\frac{p_{\rm data}(x)}{p_{\rm data}(x)+p_g(x)}
```

wherever $`p_{\rm data}(x)+p_g(x)>0`$.

**详细解析**

固定生成器后，

```math
V(D,G)=\int\big[p(x)\log D(x)+g(x)\log(1-D(x))\big]\,dx.
```

由于题目允许所有可测判别器，可以逐点优化。对 $`p(x)>0,g(x)>0`$ 的点，设 $`u=D(x)`$：

```math
\frac{d}{du}[p\log u+g\log(1-u)]=\frac pu-\frac g{1-u}=0
\quad\Longrightarrow\quad u=\frac p{p+g}.
```

二阶导数为 $`-p/u^2-g/(1-u)^2<0`$，所以它是唯一最大值。边界情况也符合公式：$`p>0,g=0`$ 时取 $`u=1`$；$`p=0,g>0`$ 时取 $`u=0`$。若 $`p=g=0`$，被积函数恒为 0，任意 $`u\in[0,1]`$ 都最优。

故在 $`p(x)+g(x)>0`$ 处，

```math
\boxed{D^*(x)=\frac{p_{\rm data}(x)}{p_{\rm data}(x)+p_g(x)}.}
```

这是对真实/生成来源使用相等先验概率时的后验概率。实际神经网络受容量与优化限制，不一定达到这个无限容量最优解。


**推导细节与进一步理解**

**为什么允许逐点最大化。** 在题目给出的无限判别器函数类中，不同 $`x`$ 的 $`D(x)`$ 没有参数共享约束，改变一个位置的输出不会迫使另一个位置也改变，因此可把积分优化分解成每个 $`x`$ 上的一元凹函数优化。实际神经网络有共享参数，所以这个推导给的是理论最优基准。

令一阶导为零后，代数过程是

```math
\frac pu=\frac g{1-u}
\quad\Longrightarrow\quad p(1-u)=gu
\quad\Longrightarrow\quad p=(p+g)u.
```

除以 $`p+g`$ 之前要检查其为正；这就是题目特意说明支持条件的原因。比如某点真实密度为 3、生成密度为 1，则最优输出是 $`3/4`$，反映该点更常来自真实数据，而不是只要它位于真实支持中就必须输出 1。

**相等先验从哪里来。** 两个期望在目标中使用同等权重，相当于真假来源先验各一半。若目标改为 $`\rho\mathbb E_p\log D+(1-\rho)\mathbb E_g\log(1-D)`$，则相同推导会给出 $`D^*=\rho p/(\rho p+(1-\rho)g)`$；因此分母中简单相加不是无条件成立的。

#### 第1题c 饱和损失与非饱和损失的梯度

**原题（PDF第1页）**

(c) During a generator update, hold the discriminator fixed and write $`D(x)=\sigma(a(x))`$, where $`a(x)`$ is its logit and $`\sigma(a)=(1+e^{-a})^{-1}`$. For one generated sample, consider

```math
\ell_{\rm sat}(a)=\log(1-\sigma(a)),\qquad
\ell_{\rm ns}(a)=-\log\sigma(a),
```

both of which are minimized by the generator. Derive their derivatives with respect to $`a`$ and use the chain rule to explain why the original loss can yield vanishing generator gradients when $`D(G_\theta(z))\approx0`$, and how the non-saturating loss addresses this.

**详细解析**

写 $`D=\sigma(a)`$，则 $`dD/da=D(1-D)`$。两种待最小化的生成器损失满足

```math
\boxed{\frac{d\ell_{\rm sat}}{da}
=\frac{d\log(1-D)}{da}=-D,}
```

```math
\boxed{\frac{d\ell_{\rm ns}}{da}
=\frac{d(-\log D)}{da}=D-1.}
```

更新生成器时判别器参数固定，但 $`a(G_\theta(z))`$ 对生成器输出的导数仍须保留。链式法则给出

```math
\nabla_\theta\ell_{\rm sat}=-D(G_\theta(z))\,\nabla_\theta a(G_\theta(z)),
```

```math
\nabla_\theta\ell_{\rm ns}=(D(G_\theta(z))-1)\,\nabla_\theta a(G_\theta(z)).
```

当 $`D(G_\theta(z))\approx0`$ 时，原损失的前置系数约为 0，判别器越容易识别假样本，生成器反而越难得到训练信号。非饱和损失的系数约为 $`-1`$，消除了这一个饱和因素。它不保证整个梯度永不消失：如果 $`\nabla_\theta a(G_\theta(z))`$ 本身很小，梯度仍可能很小。


**推导细节与进一步理解**

**把 sigmoid 的导数逐项代入。** 对饱和损失，外层对 $`D`$ 的导数为 $`-1/(1-D)`$，而内层为 $`D(1-D)`$，两者相乘是 $`-D`$。对非饱和损失，外层为 $`-1/D`$，乘以内层得到 $`-(1-D)=D-1`$。

再把生成器到 logit 的路径分开：

```math
\nabla_\theta a(G_\theta(z))
=J_{G_\theta}(z)^\top\nabla_xa(x)\big|_{x=G_\theta(z)}.
```

整个梯度由“损失对 logit 的系数”“判别器对输入的导数”“生成器对参数的导数”共同组成。非饱和损失主要修复第一部分，而不是保证后两部分也良好。

例如 $`a=-8`$ 时，$`D\approx0.000335`$，饱和损失的导数约为 $`-0.000335`$，非饱和损失的导数约为 $`-0.999665`$。在同一条后续梯度路径上，后者不会因为判别器过于确信“这是假的”就额外乘上一个接近零的因子。两者都希望增大假样本的 logit，但提供的训练信号强度不同。

### 第2题 最优 GAN 与 JS 散度

**原题（PDF第1页）**

Let $`C(G)=\max_D V(D,G)`$, where the maximization is over all measurable discriminators $`D:\mathcal X\to[0,1]`$. Define the mixture density $`m=(p_{\rm data}+p_g)/2`$ and recall

```math
D_{\rm KL}(p\Vert q)=\mathbb E_{x\sim p}\left[\log\frac{p(x)}{q(x)}\right],
```

```math
\mathrm{JSD}(p\Vert q)=\frac12D_{\rm KL}\left(p\middle\Vert\frac{p+q}{2}\right)
+\frac12D_{\rm KL}\left(q\middle\Vert\frac{p+q}{2}\right).
```

Using the optimal discriminator from Question 1, prove that

```math
C(G)=2\mathrm{JSD}(p_{\rm data}\Vert p_g)-2\log2.
```

Over all generator distributions, show that its global minimum is $`-2\log2`$, attained if and only if $`p_g=p_{\rm data}`$ almost everywhere. All logarithms are natural.

**详细解析**

**题意。** 代入最优判别器，证明 $`C(G)=2\mathrm{JSD}(p_{\rm data}\Vert p_g)-2\log2`$，再求全局最小值和等号条件。

令 $`m=(p+g)/2`$。由第1题，

```math
\begin{aligned}
C(G)
&=\int p\log\frac p{p+g}+g\log\frac g{p+g}\,dx\\
&=\int p\log\frac p m\,dx+\int g\log\frac g m\,dx
-(\log2)\left(\int p\,dx+\int g\,dx\right)\\
&=D_{\rm KL}(p\Vert m)+D_{\rm KL}(g\Vert m)-2\log2\\
&=\boxed{2\mathrm{JSD}(p\Vert g)-2\log2}.
\end{aligned}
```

由于两个 KL 均非负，

```math
\boxed{\min_{p_g}C(G)=-2\log2=-\log4.}
```

要取等号，两个非负 KL 必须同时为 0，因此 $`p=m`$ 且 $`g=m`$ 几乎处处，即 $`p_g=p_{\rm data}`$ 几乎处处。反过来若两分布相等，$`m=p=g`$，JS 为 0，所以确实取到最小值。

在匹配后的分布支持上，$`D^*=1/2`$。最优的是**生成分布**，不一定只有一套生成器参数能实现它。若限定生成器网络无法表达真实分布，则该理论下界不一定可达。

**数值检查。** 当两分布支持完全分离时，JS 为 $`\log2`$、$`C(G)=0`$；当两者相等时，JS 为 0、$`C(G)=-2\log2`$。这也解释了为什么支持分离时原始 GAN 距离可能不提供有用的连续变化信号。


**推导细节与进一步理解**

**常数为什么恰好是 $`-2\log2`$。** 由 $`p+g=2m`$，每个对数都拆成 $`\log(p/m)-\log2`$ 或 $`\log(g/m)-\log2`$。对前者用 $`p`$ 积分，常数贡献 $`-\log2\int p=-\log2`$；后者又贡献一次。因此不是 $`-\log2`$，也不是 $`-\log4`$ 再乘 2。

**两个 KL 为什么总是有定义。** $`m`$ 覆盖了两分布支持的并集；在 $`p>0`$ 的地方有 $`m\ge p/2>0`$，所以不会出现把正的 $`p`$ 除以零的问题。$`g`$ 也同理。即使 $`p`$ 与 $`g`$ 的支持互不相交，JS 仍然有限。

**达到最优时发生什么。** 当 $`p=g`$，判别器在有质量的地方只能输出 $`1/2`$，两项期望各为 $`\log(1/2)`$，总和为 $`-2\log2`$。当支持完全分离，判别器可把真样本判成 1、假样本判成 0，两项 log 都为 0，总和反而是 0。由于生成器在最小化，这说明分布匹配时目标更小，符号方向是对的。

这里先对 $`D`$ 完全优化再讨论 $`C(G)`$；实际训练只交替做有限次梯度更新，不能据此断言每次迭代的 JS 都单调下降。全局最优分布的结论也不能排除有限网络训练中的模式坍塌。

### 第3题 GigaGAN 与原始 GAN 的技术区别

**原题（PDF第1页）**

Paper: Minguk Kang, Jun-Yan Zhu, Richard Zhang, Jaesik Park, Eli Shechtman, Sylvain Paris, and Taesung Park. *Scaling up GANs for Text-to-Image Synthesis*. CVPR 2023.

Describe the technical differences between GigaGAN and the original GAN.

**详细解析**

原始 GAN 给出了 $`z\to G(z)`$ 与真假判别的通用框架，没有规定现代文本条件生成架构。GigaGAN 保留对抗训练，重新设计了可扩展的文本生成器和判别器。下表概括原论文第 3 节的设计。[论文方法部分](https://arxiv.org/html/2303.05511v2#S3)

| 方面 | 原始 GAN 框架 | GigaGAN |
|---|---|---|
| 条件输入 | 基本形式仅输入噪声 | CLIP 文本特征与噪声共同控制生成 |
| 生成器 | 通用网络 $`G(z)`$ | 风格映射、样本自适应卷积核选择、自注意力和文本交叉注意力 |
| 判别器 | 真实/生成样本判别 | 文本条件判别，多尺度输入、多尺度输出 |
| 训练信号 | 基础对抗目标 | 加入文本匹配、CLIP 对比与视觉辅助对抗信号 |
| 高分辨率 | 框架本身无专门方案 | 另训练 GAN 上采样器 |

理解时把握两条因果链即可：文本交叉注意力让局部图像特征对齐词语；多尺度判别把监督传到不同分辨率，帮助大模型训练。它仍然通过前馈生成器合成图像，基础生成器与上采样器可以分阶段运行；无需像 DDPM 那样执行一长串去噪步骤。

**推导细节与进一步理解**

**怎样把表格组织成解释。** 输入端先利用文本特征与噪声得到风格控制，同时保留词级表示供交叉注意力使用。生成器于是既有整体语义与风格控制，也能把不同空间位置关联到不同词语。自适应卷积核选择可以理解为根据当前样本在多个候选滤波器之间加权，而非所有提示使用完全相同的卷积变换。

判别器除了检查“像不像真实图像”，还要检查“图像与这段文本是否匹配”。多尺度输入和输出把监督传到粗结构及细节；错误配对的图文可作为不匹配信号，CLIP 与视觉辅助信号则引入预训练特征。这解释了为什么仅把原始 GAN 的参数数量放大，并不能自动得到相同能力。

最后区分**对抗框架**与**具体架构**：原始 GAN 是训练原则，GigaGAN 是在这一原则下为大规模文本生成图像设计的系统。两者共有生成器与判别器博弈；文本条件、网络结构、辅助损失与上采样方案才是回答技术区别时应着重比较的部分。

### 第1题 高斯噪声与前向过程

#### 第1题a 两个独立高斯的线性组合

**原题（PDF第1页）**

(a) For constants $`a,b>0`$, find the mean, variance of $`a\epsilon_1+b\epsilon_2`$. Prove the distribution is Gaussian.

**详细解析**

设 $`Y=a\epsilon_1+b\epsilon_2`$，$`\epsilon_1,\epsilon_2`$ 独立标准正态。则

```math
\mathbb EY=0,\qquad \mathrm{Var}(Y)=a^2+b^2.
```

均值与方差本身不足以证明分布为高斯。使用特征函数：标准正态的特征函数为 $`\varphi_\epsilon(u)=e^{-u^2/2}`$，由独立性，

```math
\varphi_Y(u)=\mathbb E e^{iua\epsilon_1}\,\mathbb E e^{iub\epsilon_2}
=e^{-a^2u^2/2}e^{-b^2u^2/2}=e^{-(a^2+b^2)u^2/2}.
```

这恰为 $`\mathcal N(0,a^2+b^2)`$ 的特征函数，故

```math
\boxed{a\epsilon_1+b\epsilon_2\sim\mathcal N(0,a^2+b^2).}
```

独立性不可省略；仅知道两者的边缘分布都是高斯，不能推出上述结论。


**推导细节与进一步理解**

**均值和方差各用到什么条件。** 线性期望给出 $`a\mathbb E\epsilon_1+b\mathbb E\epsilon_2=0`$。方差展开为

```math
\mathrm{Var}(a\epsilon_1+b\epsilon_2)
=a^2\mathrm{Var}(\epsilon_1)+b^2\mathrm{Var}(\epsilon_2)
+2ab\mathrm{Cov}(\epsilon_1,\epsilon_2).
```

独立性使协方差为 0，才得到 $`a^2+b^2`$。不能把系数直接相加后再平方：$`a=b=1`$ 时答案是方差 2，不是 4。

特征函数使用独立性，把一个随机和的指数期望分解成两个期望的乘积，再利用特征函数确定分布的唯一性。这一步证明了“仍是高斯”，补上了只计算均值、方差还欠缺的逻辑。若两噪声相等，和变成 $`(a+b)\epsilon_1`$，方差立刻变成 $`(a+b)^2`$，说明独立条件确实有作用。

#### 第1题b 多步加噪与直接加噪同分布

**原题（PDF第1页）**

(b) Let $`\epsilon\sim\mathcal N(0,1)`$ be independent of $`x_0`$. For any fixed step $`t`$, prove that directly sampling

```math
x_t=\sqrt{\alpha_t}x_0+\sqrt{1-\alpha_t}\epsilon
```

gives the same distribution as applying (1) $`t`$ times, with $`x_0`$ held fixed.

**详细解析**

固定 $`x_0`$，假设第 $`t-1`$ 步满足

```math
x_{t-1}\mid x_0\sim\mathcal N(\sqrt{\alpha_{t-1}}x_0,1-\alpha_{t-1}).
```

新噪声 $`\epsilon_t`$ 与此前随机变量独立，因此

```math
x_t=\sqrt{1-\beta_t}\,x_{t-1}+\sqrt{\beta_t}\,\epsilon_t
```

仍为条件高斯，其均值是

```math
\sqrt{1-\beta_t}\sqrt{\alpha_{t-1}}x_0=\sqrt{\alpha_t}x_0,
```

方差是

```math
(1-\beta_t)(1-\alpha_{t-1})+\beta_t
=1-(1-\beta_t)\alpha_{t-1}=1-\alpha_t.
```

初始 $`t=1`$ 可直接验证，归纳得

```math
\boxed{x_t\mid x_0\sim\mathcal N(\sqrt{\alpha_t}x_0,1-\alpha_t).}
```

而独立采样 $`\epsilon\sim\mathcal N(0,1)`$ 后构造
$`\sqrt{\alpha_t}x_0+\sqrt{1-\alpha_t}\epsilon`$，显然也具有此分布。

**易错点。** 同分布针对“固定 $`x_0`$、固定 $`t`$ 的条件边缘”。对每个时刻都独立使用一个直接采样公式，不会自动得到原 Markov 链的联合分布；不同时间的原链噪声状态具有相关性。


**推导细节与进一步理解**

**把等效噪声本身也构造出来。** 展开递推式可得

```math
x_t=\sqrt{\alpha_t}x_0+
\sum_{r=1}^t\sqrt{\beta_r\prod_{s=r+1}^t(1-\beta_s)}\,\epsilon_r.
```

后面是独立高斯的线性组合，其方差为 $`1-\alpha_t`$。所以可定义

```math
\epsilon^{(t)}=\frac{\sum_{r=1}^t\sqrt{\beta_r\prod_{s=r+1}^t(1-\beta_s)}\,\epsilon_r}
{\sqrt{1-\alpha_t}}\sim\mathcal N(0,1).
```

这个变量由加噪噪声组成，因而也独立于 $`x_0`$，正好满足直接采样式要求。这里的 $`\epsilon^{(t)}`$ 随时刻变化，是多个单步噪声的组合，不是简单把所有 $`\epsilon_r`$ 设成同一个随机数。

**两步数值检查。** 取 $`\beta_1=0.1,\beta_2=0.2`$，累计信号量为 $`\alpha_2=0.9\times0.8=0.72`$。第一步噪声经过第二步缩放后贡献方差 $`0.8\times0.1=0.08`$，新噪声贡献 0.2，总方差是 0.28，恰好为 $`1-0.72`$。这也是训练时可以随机选时间、直接生成带噪样本而不必跑完整前向链的依据。

### 第2题 已知干净样本时的高斯后验

**原题（PDF第1页）**

Write $`q_t(\cdot\mid\cdot)`$ for a conditional density of the forward process at step $`t`$. For $`2\leq t\leq T`$, suppose $`x_0`$ and $`x_t`$ are known. The posterior $`q_{t-1}(x_{t-1}\mid x_t,x_0)`$ describes the preceding noisy sample given these values. Following the lecture slides, denote its mean by $`\widetilde u_t(x_t,x_0)`$ and variance by $`\widetilde\beta_t`$. Prove that this posterior is Gaussian with

```math
\widetilde u_t(x_t,x_0)=\frac{\sqrt{\alpha_{t-1}}\beta_t}{1-\alpha_t}x_0
+\frac{\sqrt{1-\beta_t}(1-\alpha_{t-1})}{1-\alpha_t}x_t,
\qquad\widetilde\beta_t=\frac{1-\alpha_{t-1}}{1-\alpha_t}\beta_t.
```

**详细解析**

**题意。** 已知 $`x_0,x_t`$，求 $`x_{t-1}`$ 的条件分布。题目取 $`t\ge2`$，使下文的 $`1-\alpha_{t-1}>0`$。

记 $`y=x_{t-1}`$、$`a=1-\beta_t`$、$`A=\alpha_{t-1}`$，因此 $`\alpha_t=aA`$。前向 Markov 性和 Bayes 公式给出

```math
q(y\mid x_t,x_0)\propto q(x_t\mid y)q(y\mid x_0).
```

代入两项高斯，略去与 $`y`$ 无关的项：

```math
\begin{aligned}
\log q(y\mid x_t,x_0)
&=-\frac{(x_t-\sqrt a\,y)^2}{2\beta_t}
-\frac{(y-\sqrt A\,x_0)^2}{2(1-A)}+C\\
&=-\frac12\left(\frac a{\beta_t}+\frac1{1-A}\right)y^2
+\left(\frac{\sqrt a\,x_t}{\beta_t}+\frac{\sqrt A\,x_0}{1-A}\right)y+C'.
\end{aligned}
```

定义精度 $`P`$ 和线性系数 $`B`$：

```math
P=\frac a{\beta_t}+\frac1{1-A}
=\frac{a(1-A)+\beta_t}{\beta_t(1-A)}
=\frac{1-aA}{\beta_t(1-A)},
```

```math
B=\frac{\sqrt a\,x_t}{\beta_t}+\frac{\sqrt A\,x_0}{1-A}.
```

配方 $`-Py^2/2+By=-P(y-B/P)^2/2+B^2/(2P)`$，可知后验是高斯，方差为 $`P^{-1}`$、均值为 $`P^{-1}B`$。恢复原记号，

```math
\boxed{\widetilde\beta_t=\frac{1-\alpha_{t-1}}{1-\alpha_t}\beta_t,}
```

```math
\boxed{\widetilde u_t(x_t,x_0)
=\frac{\sqrt{\alpha_{t-1}}\beta_t}{1-\alpha_t}x_0
+\frac{\sqrt{1-\beta_t}(1-\alpha_{t-1})}{1-\alpha_t}x_t.}
```

因此 $`q(x_{t-1}\mid x_t,x_0)=\mathcal N(\widetilde u_t,\widetilde\beta_t)`$。

**易错点。** 第一个精度项是 $`(1-\beta_t)/\beta_t`$，而非 $`1/\beta_t`$；它来自平方中的 $`\sqrt{1-\beta_t}`$。此外，这里条件中已知 $`x_0`$。仅给定 $`x_t`$ 的反向条件 $`q(x_{t-1}\mid x_t)`$ 通常是混合分布，不能直接认定它与这个高斯后验相同。


**推导细节与进一步理解**

**为什么乘两个高斯会得到这个后验。** 先验项 $`q(y\mid x_0)`$ 说明在尚未观察 $`x_t`$ 前，$`y`$ 应在 $`\sqrt A x_0`$ 附近；似然项 $`q(x_t\mid y)`$ 则偏好能通过一步加噪解释当前观测的 $`y`$。二者相乘后对不兼容的 $`y`$ 同时降权。关于 $`y`$ 的指数是二次多项式，所以配方后的结果仍是高斯。

**归一化常数为何可以暂时忽略。** Bayes 分母 $`q(x_t\mid x_0)`$ 与待求变量 $`y`$ 无关，因而只影响密度整体的归一化，不影响均值和方差。配方后 $`P>0`$，故存在有限的高斯积分，归一化时补上 $`\sqrt{P/(2\pi)}`$ 即可。

**用一般条件高斯再验证。** 固定 $`x_0`$ 时，$`(x_{t-1},x_t)`$ 的均值和协方差为

```math
\begin{pmatrix}\sqrt A x_0\\\sqrt{aA}x_0\end{pmatrix},\qquad
\begin{pmatrix}1-A&\sqrt a(1-A)\\\sqrt a(1-A)&1-aA\end{pmatrix}.
```

条件均值是 $`\sqrt A x_0+\frac{\sqrt a(1-A)}{1-aA}(x_t-\sqrt{aA}x_0)`$，条件方差是 $`(1-A)-a(1-A)^2/(1-aA)`$。展开后恰好得到题目要求的两个系数和 $`\widetilde\beta_t`$。这里的系数不是普通概率权重，不能强行要求两个均值系数相加等于 1。

**后验方差应比新加噪声小。** 因为 $`\alpha_t<\alpha_{t-1}`$，比值 $`(1-\alpha_{t-1})/(1-\alpha_t)<1`$，所以 $`0<\widetilde\beta_t<\beta_t`$。已知干净样本与当前样本提供了额外信息，这个不确定性缩减符合直觉。

### 第3题 潜空间扩散模型 LDM

**原题（PDF第1页）**

Paper: Rombach et al., *High-Resolution Image Synthesis with Latent Diffusion Models* (CVPR 2022).

Answer the following briefly in words or with a simple diagram.

#### 第3题a 编码器 解码器与扩散模型怎样组合

**原题（PDF第1页）**

(a) How are the VAE-style autoencoder and the diffusion model combined in a latent diffusion model (LDM)? Describe the roles of the encoder, decoder, and diffusion model. In which space is noise added?

**详细解析**

编码器 $`E`$ 把图像压缩为低维潜表示 $`z_0`$；扩散模型学习潜表示的生成分布；解码器 $`D`$ 将最终潜表示还原为图像。加噪和逐步去噪都发生在**潜空间**。

```text
训练：图像 x → 编码器 E → z₀ → 加噪 zₜ → 噪声预测网络
生成：高斯 z_T → 潜空间逐步去噪 → z₀ → 解码器 D → 图像
```


**推导细节与进一步理解**

**三个模块分别学习什么。** 编码器学习把图像变成仍保留重要视觉信息的潜表示，解码器学习从这种表示恢复图像；扩散网络则学习这些潜表示在数据集中的分布。前两者解决“怎样压缩和重建”，后者解决“怎样生成新的、合理的潜表示”。

因此不能把 LDM 理解成“训练好 VAE 后直接从其标准正态先验解码”。第一阶段的潜空间正则通常较弱，其聚合分布未必就是简单标准高斯；第二阶段的扩散模型正是在学习更强的潜空间生成先验。它也不是先在像素中去噪、最后才编码，噪声加到哪里是本问的核心区分。

#### 第3题b 两阶段训练

**原题（PDF第1页）**

(b) How is an LDM trained? Describe the two training stages. Which components are trained first, and which are kept fixed when training the diffusion model? What are the diffusion model’s prediction target and loss?

**详细解析**

先训练自编码器，使压缩后的表示可重建图像；原论文使用感知和对抗重建损失，并研究 KL 或 VQ 正则。再固定编码器与解码器，在编码后的潜变量上训练扩散网络；有条件生成时也可训练条件模块。常见目标是预测加入的标准高斯噪声，用均方误差训练。[LDM 原论文第 3 节](https://arxiv.org/html/2112.10752v2#S3)

用本作业累计记号表达，

```math
z_t=\sqrt{\alpha_t}z_0+\sqrt{1-\alpha_t}\epsilon,\qquad
L=\mathbb E\|\epsilon-\epsilon_\theta(z_t,t,c)\|_2^2.
```

这里 $`c`$ 是可选条件。训练不要求先顺序生成所有中间噪声状态，随机抽取 $`t`$ 后可以直接构造 $`z_t`$。


**推导细节与进一步理解**

**第一阶段的训练数据流。** 输入真实图像 $`x`$，计算 $`z_0=E(x)`$ 和重建 $`\widehat x=D(z_0)`$，用重建质量相关的损失更新自编码器。KL 正则版本还约束编码分布，VQ 版本则使用码本正则；它们提供不同形式的表示约束，不意味着扩散阶段要重新训练第一阶段所有参数。

**第二阶段的一次训练迭代。** 先用固定编码器得到 $`z_0`$，独立抽取 $`t`$ 和 $`\epsilon`$，构造 $`z_t`$，输入带时间条件的网络得到 $`\widehat\epsilon`$，再以 $`\|\epsilon-\widehat\epsilon\|^2`$ 反向传播更新扩散网络。目标噪声是训练时确切抽到的那个 $`\epsilon`$，不是要求模型在不知道 $`z_0`$ 的情况下直接计算解析后验。

固定自编码器使扩散模型训练时面对一个稳定的表示空间，避免编码分布不断漂移。条件分支是否训练取决于具体方案；题目问的确定冻结对象是第一阶段的编码器与解码器，不应据此断言所有文本编码器在所有实现里都冻结。

#### 第3题c 推理顺序

**原题（PDF第1页）**

(c) How does inference generate a new image from random noise? Describe the steps in order, including where denoising takes place and when the decoder is used.

**详细解析**

先从标准高斯采样 $`z_T`$，在潜空间按所选采样器逐步得到 $`z_{T-1},\ldots,z_0`$，最后才调用解码器产生图像。无条件生成不需要输入图像，也不需要先经过编码器；文本条件生成还需准备文本条件。潜变量若做过固定缩放，解码前按模型约定还原缩放。

**推导细节与进一步理解**

**按执行顺序写出完整生成流程。** 准备提示条件 $`c`$（若无条件则省略），抽取与潜空间形状一致的高斯噪声 $`z_T`$，把 $`(z_T,T,c)`$ 输入去噪网络；采样器结合网络预测与噪声日程得到 $`z_{T-1}`$。重复这一过程，直到取得干净潜表示 $`z_0`$，再按缩放约定送入解码器，得到图像。

解码器一般只在潜空间采样完成后使用一次；若为了显示中间进度而解码若干中间状态，那是可选可视化，并非基本算法必需。编码器在无条件或纯文本生成时不提供初始图像；在图像编辑等任务中才可能用它编码输入图像。

计算节省主要来自反复执行的去噪网络工作在较小的空间网格上，解码到高分辨率的成本只承担在末尾。压缩仍可能损失细节，因此自编码器的重建能力也限制了最终可恢复的信息。

### 第1题 预训练 指令微调与强化微调

**原题（PDF第1页）**

**Pre-training, instruction fine-tuning, and reinforcement fine-tuning**

Compare these three training stages for language models in terms of the data used, the training objective and feedback signal, and the role of each stage. Explain how learning from reference responses differs from learning from rewards assigned to model-generated responses. This is a discussion question. Answer in words; no mathematical formulas are required.

**详细解析**

| 阶段 | 使用的数据 | 目标与反馈信号 | 作用 |
|---|---|---|---|
| 预训练 | 大量文本、代码等序列，通常不逐条人工标答案 | 根据前文预测下一个 token，以真实后续 token 提供自监督信号 | 学习语言结构、知识和可迁移的表示与能力 |
| 指令微调 | 指令或提示及其参考回答 | 在给定提示时提高参考回答中各 token 的概率；反馈来自示范答案 | 让已有能力以遵循指令、完成任务的形式表现出来 |
| 强化微调 | 提示、当前策略采样出的回答，以及对这些回答的奖励 | 提高期望奖励；反馈可来自验证器、环境或奖励模型，也可加入与参考策略的距离约束 | 在多个可能回答中偏向任务成功、可验证正确或更受偏好的行为 |

从参考回答学习时，训练数据直接告诉模型“应当怎样回答”，常以真实前缀预测下一 token。即使模型没有自行生成该完整回答，也能学习这个示范。

从奖励学习时，模型先生成回答，再获得质量评价。奖励通常不逐 token 指定正确文本，而是评价整个回答或某个过程步骤。模型需要把这种评价转换成改变生成概率的训练信号。两个措辞不同但都正确的回答可以同时得高分；一个看起来像示范但没有解决问题的回答也可能得低分。

三阶段分别侧重基础能力、指令行为和奖励所描述的成功标准。强化微调的效果取决于奖励与真实目标的一致性；只优化某个评分器，不自动保证所有维度的回答质量同步改善。


**推导细节与进一步理解**

**用同一个任务比较三种反馈。** 以回答数学问题为例：预训练阶段，模型在教材、网页或代码文本中学习常见表达和推理模式；指令微调阶段，训练数据提供“这道问题以及一份示范解答”，模型学习照着这种问题回答；强化微调阶段，模型先自行尝试，验证器再检查最终答案是否正确，或者对推理过程给出评价。

示范监督不仅告诉模型什么答案好，还逐步给出希望它模仿的文本。奖励监督可以告诉模型某个尝试成功或失败，却通常没有给出唯一的标准措辞，也没有直接告诉每个位置应该写哪个词。因此后者需要探索不同回答，并解决如何把整体奖励分配到生成行为的问题。

**数据来源与训练方式不能混为一谈。** 指令微调的示范也可以来自另一个模型，奖励也可以由自动程序产生；“人工还是自动”不是区分这三个阶段的唯一标准。真正要比较的是模型看到了什么数据、优化什么目标，以及反馈直接监督参考文本还是评价它自己的回答。强化微调也不会凭空弥补所有知识缺口，它通常是在已有策略的基础上改变行为偏好。

### 第2题 对数导数技巧

**原题（PDF第1页）**

For a fixed prompt, let $`p(s;\theta)`$ be a differentiable probability mass function over responses $`s`$, with $`\theta\in\mathbb R^d`$. Let $`R(s)`$ be a reward function that does not depend on $`\theta`$, and define

```math
J(\theta)=\mathbb E_{s\sim p(\cdot;\theta)}[R(s)].
```

Assume that $`p(s;\theta)>0`$ on a parameter-independent support, that all required expectations are finite, and that differentiation and summation may be interchanged. Prove the identities

```math
\nabla_\theta p(s;\theta)=p(s;\theta)\nabla_\theta\log p(s;\theta),
\qquad\nabla_\theta J(\theta)=\mathbb E_{s\sim p(\cdot;\theta)}[R(s)\nabla_\theta\log p(s;\theta)].
```

**详细解析**

**题意。** $`R(s)`$ 不依赖参数，$`p(s;\theta)>0`$ 且支持与参数无关。证明概率导数与期望奖励梯度两个恒等式。

由链式法则，

```math
\nabla_\theta\log p(s;\theta)=\frac{\nabla_\theta p(s;\theta)}{p(s;\theta)}.
```

两边乘以正数 $`p(s;\theta)`$ 即得

```math
\boxed{\nabla_\theta p(s;\theta)=p(s;\theta)\nabla_\theta\log p(s;\theta).}
```

再按题设交换求和与求导：

```math
\begin{aligned}
\nabla_\theta J(\theta)
&=\nabla_\theta\sum_s p(s;\theta)R(s)\\
&=\sum_sR(s)\nabla_\theta p(s;\theta)\\
&=\sum_sp(s;\theta)R(s)\nabla_\theta\log p(s;\theta)\\
&=\boxed{\mathbb E_{s\sim p}[R(s)\nabla_\theta\log p(s;\theta)]}.
\end{aligned}
```

因此，用采样回答的 $`R(s)\nabla_\theta\log p(s;\theta)`$ 可无偏估计梯度，无需奖励函数对回答可微。语言模型中，完整回答的 log 概率是各 token 条件 log 概率之和。

另一个有用恒等式是 score 的期望为 0：

```math
\mathbb E_p[\nabla_\theta\log p(s;\theta)]
=\sum_s\nabla_\theta p(s;\theta)=\nabla_\theta1=0.
```

故对固定提示下不随回答变化的基线 $`b`$，$`\mathbb E[(R-b)\nabla\log p]=\nabla J`$。若奖励显式依赖 $`\theta`$，则还需要 $`\mathbb E[\nabla_\theta R]`$；本题已排除此情况。


**推导细节与进一步理解**

**为什么有的地方要对采样概率求导。** $`R(s)`$ 虽然不依赖参数，但它的期望依赖 $`\theta`$，因为不同回答被采到的概率在改变。若只对已经采出的奖励值求普通导数，会得到 0，遗漏整个概率重加权效应。对数导数技巧正是把这部分影响写成可采样估计的形式。

以有限的三个回答为例，设其概率分别为 $`p_1,p_2,p_3`$，则 $`J=p_1R_1+p_2R_2+p_3R_3`$，所以 $`\nabla J=R_1\nabla p_1+R_2\nabla p_2+R_3\nabla p_3`$。再把每个 $`\nabla p_i`$ 写成 $`p_i\nabla\log p_i`$，才得到关于当前采样分布的期望。

**完整回答的梯度如何落到 token 上。** 如果回答 $`s=(y_1,\ldots,y_L)`$，则

```math
\log p_\theta(s)=\sum_{t=1}^L\log p_\theta(y_t\mid y_{<t},\text{prompt}),\qquad
\nabla_\theta\log p_\theta(s)=\sum_{t=1}^L\nabla_\theta\log p_\theta(y_t\mid y_{<t},\text{prompt}).
```

所以一句回答的奖励可以乘在整段 log 概率梯度上。若响应长度是随机的，应把终止行为也包含在完整分布定义中。题目关于固定支持与交换求导求和的条件，保证这些代数步骤成立。

### 第3题 常数奖励与基线

**原题（PDF第1页）**

Use the setup of Question 2, with $`\theta\in\mathbb R`$ and $`R(s)=1`$ for every response $`s`$.

#### 第3题a 每个参数都是最优解

**原题（PDF第1页）**

(a) Show that $`J(	heta)=1`$ for every $`	heta`$, so every $`	heta`$ is optimal.

**详细解析**

$`R(s)=1`$，所以

```math
\boxed{J(\theta)=\sum_sp(s;\theta)=1,\quad\forall\theta.}
```

目标是常数，所有参数的目标值相同且都达到最大值，真实梯度为 0。


**推导细节与进一步理解**

**最优与驻点在本题中为何都成立。** 因为无论概率质量怎样在响应间移动，每个响应给出的奖励都还是 1，所以重新分配概率不会改变期望奖励。这里不仅有某个局部平坦点，而是整个参数域的目标函数都相同；因此任意参数都是全局最大值点，同时真实梯度处处为零。

这并不意味着所有策略输出相同，也不意味着模型参数不再影响采样结果；它只意味着当前这个常数奖励函数分不出这些策略的优劣。如果换成能区分答案正确与否的奖励，结论一般就不再成立。

#### 第3题b 单个样本仍可能导致非零更新

**原题（PDF第1页）**

(b) For one sampled response $`s\sim p(\cdot;\theta)`$, consider the update

```math
\Delta\theta=\eta\frac{d}{d\theta}\log p(s;\theta),\qquad\eta>0.
```

Assume $`\frac{d}{d\theta}\log p(s;\theta)\ne0`$. Show that $`\Delta\theta\ne0`$, even though $`\theta`$ is already optimal.

**详细解析**

令 $`h(s;\theta)=\frac d{d\theta}\log p(s;\theta)`$。题目假定这个样本满足 $`h\ne0`$，又因为 $`\eta>0`$，

```math
\boxed{\Delta\theta=\eta h(s;\theta)\ne0.}
```

这与真实梯度为 0 不矛盾：$`\mathbb E_p h=0`$ 只表示不同样本的更新在期望上抵消，不表示每个样本更新都等于 0。若二阶矩存在，

```math
\mathrm{Var}(\Delta\theta)=\eta^2\mathbb E_p[h^2].
```

例如 $`s\in\{0,1\}`$，$`p(s=1;\theta)=\sigma(\theta)`$。在 $`\theta=0`$ 时，$`h=s-1/2`$，单次更新为 $`\pm\eta/2`$，均值 0、方差 $`\eta^2/4`$。移动之后仍处于最优点，因为整个目标都是常数。


**推导细节与进一步理解**

**单次更新为何会偏向刚抽到的回答。** 对数概率的梯度指向提高该样本概率的方向，所以一个奖励为 1 的样本依然会引发非零更新。在另一次抽样中，其他回答可能引发相反方向的更新；只有对全部样本按当前概率加权平均，才恢复真实的零梯度。

题目只要求证明这个给定样本的更新非零，直接使用 $`\eta>0`$ 与导数非零即可。不要额外假设“最优参数必须让每个样本的 log probability 梯度为零”，这一般不成立。也不要把本题移动解释成目标一定变差，因为移动前后期望奖励始终都是 1。

对于前面的 Bernoulli 例子，可以显式写成：$`s=1`$ 的梯度为 $`1-p`$，$`s=0`$ 的梯度为 $`-p`$。以概率 $`p,1-p`$ 加权后，$`p(1-p)+(1-p)(-p)=0`$；每个样本却通常都不为零。

#### 第3题c 取基线 1 后样本方差为零

**原题（PDF第1页）**

(c) Now use the baseline $`b=1`$, giving the update

```math
\Delta\theta_b=\eta\big(R(s)-b\big)\frac{d}{d\theta}\log p(s;\theta).
```

Show that $`\Delta\theta_b=0`$ for every sample, and hence $`\mathrm{Var}(\Delta\theta_b)=0`$.

**详细解析**

题式应理解为 $`\eta(R(s)-b)\frac d{d\theta}\log p(s;\theta)`$。取 $`b=1`$，则每个样本都有

```math
\boxed{\Delta\theta_b=\eta(1-1)h(s;\theta)=0,\qquad
\mathrm{Var}(\Delta\theta_b)=0.}
```

基线扣除了所有回答共有的奖励，使无差别的“人人得 1 分”不再产生采样噪声。本题中它同时保留了正确的零期望梯度；一般奖励下使用基线不会自动使方差归零。


**推导细节与进一步理解**

**基线为何保留期望。** 对固定提示下与回答无关的 $`b`$，

```math
\mathbb E_p[(R-b)\nabla\log p]
=\mathbb E_p[R\nabla\log p]-b\underbrace{\mathbb E_p[\nabla\log p]}_{0}.
```

因此扣除基线改变样本更新的离散程度，而不改变目标梯度。本题恰好每个奖励都等于这个基线，所以每个优势 $`R-b`$ 都是零，随机性被完全消除。

“不依赖回答”的条件有实质作用。若随意令基线 $`b=b(s)`$，通常不能把它从期望中提出来，$`\mathbb E[b(s)\nabla\log p]`$ 也未必为零。实践中可使用依赖提示或状态的基线，但要保证它不因当前抽到哪个动作或回答而任意变化；学习基线时还需正确处理梯度路径。

### 第4题 KL 正则下的最优策略

**原题（PDF第1页）**

Paper: Rafael Rafailov et al. *Direct Preference Optimization: Your Language Model is Secretly a Reward Model*. NeurIPS 2023.

For a fixed prompt, let $`S`$ be a finite response set, $`p_{\rm ref}(s)>0`$ a reference distribution on $`S`$, $`R(s)\in\mathbb R`$ a reward, and $`\beta>0`$. Over all probability distributions $`p`$ on $`S`$, we wish to maximize

```math
F(p)=\mathbb E_{s\sim p}[R(s)]-\beta D_{\rm KL}(p\Vert p_{\rm ref}).
```

Define

```math
p^*(s)=\frac1Zp_{\rm ref}(s)\exp\left(\frac{R(s)}\beta\right),
\qquad Z=\sum_{s\in S}p_{\rm ref}(s)\exp\left(\frac{R(s)}\beta\right).
```

题设 $`S`$ 有限、$`p_{\rm ref}(s)>0`$、奖励有限且 $`\beta>0`$，因此

```math
Z=\sum_{s\in S}p_{\rm ref}(s)e^{R(s)/\beta}\in(0,\infty),\qquad
p^*(s)=Z^{-1}p_{\rm ref}(s)e^{R(s)/\beta}>0
```

确实定义了一个概率分布。此结论对应 DPO 论文附录 A.1 中的闭式最优策略。[原论文附录 A.1](https://arxiv.org/html/2305.18290v3#A1.SS1)

#### 第4题a 展开 KL 得到恒等式

**原题（PDF第1页）**

(a) By expanding $`D_{\rm KL}(p\Vert p^*)`$, prove that

```math
F(p)=\beta\log Z-\beta D_{\rm KL}(p\Vert p^*).
```

**详细解析**

由

```math
\log p^*(s)=\log p_{\rm ref}(s)+\frac{R(s)}\beta-\log Z,
```

可得

```math
\begin{aligned}
D_{\rm KL}(p\Vert p^*)
&=\sum_s p(s)\left[\log\frac{p(s)}{p_{\rm ref}(s)}-\frac{R(s)}\beta+\log Z\right]\\
&=D_{\rm KL}(p\Vert p_{\rm ref})-\frac1\beta\mathbb E_pR+\log Z.
\end{aligned}
```

乘以 $`-\beta`$ 并移项：

```math
\boxed{F(p)=\mathbb E_pR-\beta D_{\rm KL}(p\Vert p_{\rm ref})
=\beta\log Z-\beta D_{\rm KL}(p\Vert p^*).}
```

$`p(s)=0`$ 的项按 $`0\log0=0`$ 解释；由于 $`p^*(s)>0`$，这里不存在分母为零的问题。


**推导细节与进一步理解**

**把常数项与依赖策略的项分清。** $`Z`$ 由固定的奖励、参考分布和温度决定，对正在优化的候选分布 $`p`$ 而言是常数。展开 KL 后的 $`\sum_sp(s)\log Z=\log Z`$，用到的是概率归一化 $`\sum_sp(s)=1`$；不能把 $`Z`$ 误当作随候选 $`p`$ 改变的量。

从原目标也能直接读出同一个重写：

```math
\begin{aligned}
F(p)&=\beta\sum_sp(s)\log\frac{p_{\rm ref}(s)e^{R(s)/\beta}}{p(s)}\\
&=\beta\sum_sp(s)\log\frac{Zp^*(s)}{p(s)}\\
&=\beta\log Z-\beta D_{\rm KL}(p\Vert p^*).
\end{aligned}
```

这说明原本“高奖励”和“少偏离参考”两个相互制约的项，可以合并为“接近一个确定目标分布”的单一 KL。这里是分布层面的精确恒等式，不涉及采样近似或神经网络训练是否收敛。

#### 第4题b 全局最优与唯一性

**原题（PDF第1页）**

(b) Use the non-negativity of KL divergence and its equality condition to prove that $`p^*`$ is the unique maximizer of $`F(p)`$.

**详细解析**

KL 非负，且 $`\beta>0`$，故

```math
F(p)\le\beta\log Z.
```

取 $`p=p^*`$ 时 KL 为 0，达到上界。若其他分布也达到上界，就必须满足 $`D_{\rm KL}(p\Vert p^*)=0`$，由 KL 的等号条件推出 $`p(s)=p^*(s)`$ 对所有 $`s`$ 成立。因此

```math
\boxed{p^*\text{ 是唯一最优分布，且 }\max_pF(p)=\beta\log Z.}
```

这里唯一的是分布，不意味着神经网络的参数表示也唯一。闭式结果表明：最优策略把参考概率按 $`e^{R/\beta}`$ 重新加权，再统一归一化。给所有奖励加同一个常数不会改变最优策略；当奖励恒定时，最优策略就是 $`p_{\rm ref}`$。

**推导细节与进一步理解**

**一个可以手算的最优策略。** 两个回答的参考概率均为 $`1/2`$，奖励为 $`R_1=0,R_2=\log3`$，取 $`\beta=1`$，则未归一化权重是 $`1/2,3/2`$，$`Z=2`$，故 $`p^*=(1/4,3/4)`$，最优目标值为 $`\log2`$。高奖励回答获得更大概率，但另一个回答并没有被直接删掉，因为参考分布的偏离代价仍然存在。

**唯一性证明需要哪一步。** 只说 KL 非负，只能推出一个上界；还要说明 $`p^*`$ 能达到上界，以及 KL 为零当且仅当两个分布完全相同，才能得到唯一最优。题设参考分布处处正、奖励有限，保证 $`p^*`$ 也处处正，所以所有候选策略的零概率项都可以按标准约定处理。

**温度与奖励平移。** 给每个回答奖励加同一个常数 $`c`$，分子和 $`Z`$ 都乘 $`e^{c/\beta}`$，最优概率不变。$`\beta`$ 很大时参考约束更强，策略靠近 $`p_{\rm ref}`$；$`\beta`$ 趋近零时，策略集中到奖励最高的回答，若并列则保留这些回答之间的参考相对权重。

与 DPO 的联系是可以反解 $`R(s)=\beta\log[p^*(s)/p_{\rm ref}(s)]+\beta\log Z`$；比较两个回答的奖励差时，最后的共同常数抵消。这也说明最优策略关心相对奖励，而不是奖励的绝对零点。

**Gaussian distribution.** The probability density function of the multivariate Gaussian distribution $`\mathcal N(\mu,\Sigma)`$ is given by

```math
f(x)=\frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}
\exp\left(-\frac12(x-\mu)^\top\Sigma^{-1}(x-\mu)\right),
```

where $`\mu\in\mathbb R^d`$ is the mean vector, $`\Sigma\in\mathbb R^{d\times d}`$ is the covariance matrix.

**f-divergence.** Let $`f(\cdot):[0,+\infty)\to\mathbb R`$ be a continuous convex function satisfying $`f(1)=0`$. Then the f-divergence between two continuous probability density functions $`p(x)`$ and $`q(x)`$ is defined as:

```math
D_f(p\Vert q)=\int q(x)f\left(\frac{p(x)}{q(x)}\right)dx.
```

### 第1题 自回归模型

#### 第1题a Transformer 与 RNN 的训练及推理效率

**原题（PDF第1页）**

(a) (5 points) RNN and Transformer are the most popular architectures in language modeling. Given a sequence of length $`n`$, during training, what is the order of computation complexity of Transformers and RNN with respect to $`n`$? Which one is more training-efficient? During inference, what is the order of computation complexity of the transformer and RNN with respect to $`n`$? Which one is more inference-efficient?

**详细解析**

**答案需要同时区分运算量和并行性。** 固定隐藏维度、层数，以生成或训练长度 $`n`$ 的完整序列计：

| 阶段 | RNN | 标准稠密 Transformer |
|---|---|---|
| 训练总运算量 | $`O(n)`$ | $`O(n^2)`$ |
| 训练时位置间依赖 | 隐状态沿位置顺序计算 | teacher forcing 下各位置可并行，层内没有 RNN 式的逐 token 递推 |
| 生成 $`n`$ 个 token 的总运算量 | $`O(n)`$，缓存隐状态 | 使用 KV cache 时 $`O(n^2)`$ |
| 自回归推理顺序 | 逐 token | 同样逐 token |

保留维度 $`d`$ 时，RNN 主成本可写成 $`O(nd^2)`$；Transformer 一层训练为 $`O(nd^2+n^2d)`$。有 KV cache 时第 $`t`$ 个新 token 的投影成本约 $`O(d^2)`$，与已有键值交互为 $`O(td)`$，对 $`t`$ 求和得 $`O(nd^2+n^2d)`$。

**考试简答。** Transformer 训练时能并行处理序列，通常更充分利用 GPU；RNN 受顺序依赖限制。推理时两者均须逐 token 生成，而 RNN 每步只维护固定维度隐状态，关于序列长度的计算成本更低。不能把“训练更高效”解释成 Transformer 的总 FLOPs 更少；实际速度还取决于硬件与规模。

**实现条件。** 上述 Transformer 推理的 $`O(n^2)`$ 使用 KV cache。若每一步都重算整个前缀，注意力总运算可达 $`O(n^3)`$。因此答复杂度时应写清缓存假设。


**推导细节与进一步理解**

**训练为什么能同时得到所有预测。** 在 teacher forcing 下，真实前缀都已知。Transformer 可以先对整个输入做投影，再一次计算所有合法的查询与键交互，因果掩码保证没有泄漏；RNN 的 $`h_t=F(h_{t-1},x_t)`$ 则必须先得到 $`h_{t-1}`$。因此前者总运算量更高，却有更强的位置并行性。

**推理的二次项怎样累加。** 使用 KV cache 时，第 $`t`$ 步的新查询仍要读取历史 $`t`$ 个键并汇总 $`t`$ 个值。固定维度后，注意力交互总量为

```math
1+2+\cdots+n=\frac{n(n+1)}2=O(n^2).
```

RNN 每步用固定尺寸隐状态更新，累计为 $`n`$ 次固定成本。若不用 KV cache，每步都重算长度 $`t`$ 的完整注意力矩阵，则有 $`\sum_{t=1}^nt^2=O(n^3)`$。所以“缓存后单步线性”与“完整生成过程线性”必须分开。

答题时可先给固定维度下的 $`O(n)`$ 与 $`O(n^2)`$，再说明训练依赖并行计算而推理存在因果顺序。效率判断是对这些结构特点的比较，不能仅用 Big O 直接断言所有硬件上的实测速度。

#### 第1题b 为什么需要位置编码

**原题（PDF第2页）**

(b) (5 points) Briefly explain why the transformer model needs positional embeddings to process a sequence.

**详细解析**

没有位置相关信息的全连接自注意力是**排列等变**的：若用置换矩阵 $`P`$ 置换输入，$`Q,K,V`$ 相应变为 $`PQ,PK,PV`$，有

```math
\mathrm{Attention}(PQ,PK,PV)
=P\mathrm{Attention}(Q,K,V).
```

模型仅靠内容相似度难以表达词语的位置、相对距离和顺序。位置编码把这些信息加入表示或查询与键的运算中，例如学习的位置向量、正弦位置编码和 RoPE。

严格来说，这里是“等变”而非“输出完全不变”。因果掩码本身也引入了顺序结构，因此不能把上述无掩码等变性质原封不动地用于固定因果掩码；通常仍使用位置编码来显式提供所需的位置和距离信息。


**推导细节与进一步理解**

**等变性的关键计算。** 置换后分数矩阵变为 $`PSP^\top`$，按行 softmax 满足

```math
\mathrm{softmax}_{\rm row}(PSP^\top)
=P\mathrm{softmax}_{\rm row}(S)P^\top.
```

再乘置换后的值矩阵 $`PV`$，中间的 $`P^\top P`$ 抵消，输出仅跟着输入一起置换。这说明注意力本身没有额外的序列坐标，不能只依靠内容匹配提供所有位置关系。

例如相同词语以不同顺序出现时，语法角色和依赖距离可能改变。加法位置编码为同一个词在不同位置提供不同输入；相对位置偏置或 RoPE 则直接影响不同位置之间的注意力关系。它们是不同实现，回答“为什么需要”时先说明缺少什么信息，再举一种如何补充该信息的方式即可。

#### 第1题c 自注意力的计算

**原题（PDF第2页）**

(c) (5 points) Given the sequence of queries $`q_1,\ldots,q_n\in\mathbb R^d`$, keys $`k_1,\ldots,k_n\in\mathbb R^d`$, and values $`v_1,\ldots,v_n\in\mathbb R^d`$, describe how the self-attention mechanism works on those queries, keys, and values.

**详细解析**

把给定向量按行堆成 $`Q,K,V\in\mathbb R^{n\times d}`$。计算

```math
\boxed{O=\mathrm{softmax}_{\rm row}\left(\frac{QK^\top}{\sqrt d}\right)V.}
```

对每个查询 $`q_i`$，

```math
s_{ij}=\frac{q_i^\top k_j}{\sqrt d},\qquad
a_{ij}=\frac{e^{s_{ij}}}{\sum_{r=1}^n e^{s_{ir}}},\qquad
o_i=\sum_{j=1}^n a_{ij}v_j.
```

也就是先算查询与每个键的相关性，再归一化为权重，最后加权汇总值向量。用于本课程自回归语言模型时，在 softmax 前屏蔽 $`j>i`$ 的分数。


**推导细节与进一步理解**

**手算一个查询的权重。** 若某查询与两个键的缩放分数分别为 $`0,\log3`$，则 softmax 权重是 $`1/4,3/4`$。如果两个值向量为 $`(1,0)`$、$`(0,2)`$，该查询输出为 $`(1/4,3/2)`$。这说明键决定权重，值提供被汇总的内容，输出不是在键中做一次硬选择。

完整矩阵中第 $`i`$ 行 softmax 必须对所有可见键归一化，所以分母的求和指标与键位置一致。分数矩阵是 $`n\times n`$，输出是 $`n\times d`$；如果在自回归问题中额外加入因果掩码，求和范围从全体键改为 $`j\le i`$，加权求和机制本身不变。

#### 第1题d LayerNorm 的数值答案

**原题（PDF第2页）**

(d) (5 points) The data batch $`X`$ contains one sequence of four 2-dimensional vectors. For simplicity, we set the parameter $`\epsilon=0`$, the rescale mean $`\beta=0`$, and the rescale standard variation $`\gamma=1`$. Compute the output of layer normalization operating on $`X`$.

```math
X=\left[\begin{pmatrix}2\\1\end{pmatrix},
\begin{pmatrix}0\\2\end{pmatrix},
\begin{pmatrix}2\\0\end{pmatrix},
\begin{pmatrix}4\\1\end{pmatrix}\right].
```

**详细解析**

原题有四个二维 token：$`(2,1)^\top,(0,2)^\top,(2,0)^\top,(4,1)^\top`$。LayerNorm 在**每个 token 的特征维**上独立计算，方差除以特征数 2：

```math
\mu=\frac{x_1+x_2}2,\qquad v=\frac{(x_1-\mu)^2+(x_2-\mu)^2}2,\qquad
\mathrm{LN}(x)=\frac{x-\mu}{\sqrt v}.
```

| token | 均值 | 方差 | 标准差 | 输出 |
|---|---:|---:|---:|---|
| $`(2,1)`$ | $`1.5`$ | $`0.25`$ | $`0.5`$ | $`(1,-1)`$ |
| $`(0,2)`$ | $`1`$ | $`1`$ | $`1`$ | $`(-1,1)`$ |
| $`(2,0)`$ | $`1`$ | $`1`$ | $`1`$ | $`(1,-1)`$ |
| $`(4,1)`$ | $`2.5`$ | $`2.25`$ | $`1.5`$ | $`(1,-1)`$ |

所以保持原题按列展示的写法，

```math
\boxed{\mathrm{LN}(X)=
\left[\begin{pmatrix}1\\-1\end{pmatrix},
\begin{pmatrix}-1\\1\end{pmatrix},
\begin{pmatrix}1\\-1\end{pmatrix},
\begin{pmatrix}1\\-1\end{pmatrix}\right].}
```

这里 $`\epsilon=0,\gamma=1,\beta=0`$；不使用无偏样本方差，不跨四个位置一起归一化。


**推导细节与进一步理解**

**把第一个向量逐步算完。** 对 $`x=(2,1)^\top`$，先算均值 $`\mu=1.5`$，中心化结果是 $`(0.5,-0.5)`$；平方后是 $`(0.25,0.25)`$，平均得方差 0.25，开平方得标准差 0.5；最后逐分量相除得到 $`(1,-1)`$。第四个向量的中心化结果为 $`(1.5,-1.5)`$、标准差为 1.5，所以输出同样是 $`(1,-1)`$。

更一般地，二维向量 $`(a,b)`$ 的均值是 $`(a+b)/2`$，中心化后为 $`((a-b)/2,(b-a)/2)`$，方差为 $`(a-b)^2/4`$。当 $`a\ne b`$ 且 $`\epsilon=0`$，归一化结果就是

```math
\mathrm{LN}(a,b)=(\mathrm{sign}(a-b),-\mathrm{sign}(a-b)).
```

这说明本题各向量相差很大，输出仍只有两种形式并不奇怪。若两个分量完全相等，方差会是 0，本题指定 $`\epsilon=0`$ 时归一化没有定义；给定四个向量都避免了这一情况。实际 LayerNorm 通常保留正的 $`\epsilon`$，且可以学习 $`\gamma,\beta`$。

### 第2题 VAE

#### 第2题a 证明变分下界

**原题（PDF第2页）**

(a) (10 points) Let $`Z`$ be the latent variable. Let $`p(z)`$ be the prior distribution. Assume the conditional density function $`p_\theta(x\mid z)`$ is parametrized by a neural network $`\theta`$, the posterior distribution $`q_\phi(z\mid x)`$ is parametrized by a neural network $`\phi`$. Prove the variational lower bound

```math
\log p_\theta(x)\geq\mathbb E_{q_\phi(z\mid x)}
\left[\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\right].
```

**详细解析**

固定 $`x`$，利用 $`\log`$ 的凹性，在题目默认的支持与可积条件下，

```math
\begin{aligned}
\log p_\theta(x)
&=\log\int q_\phi(z\mid x)\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\,dz\\
&=\log\mathbb E_{q_\phi(z\mid x)}\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\\
&\ge\mathbb E_{q_\phi(z\mid x)}\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}.
\end{aligned}
```

这就是所求 ELBO。又有

```math
\log p_\theta(x)-\mathrm{ELBO}
=D_{\rm KL}(q_\phi(z\mid x)\Vert p_\theta(z\mid x))\ge0.
```

所以等号当且仅当近似后验等于真实后验，几乎处处成立。将联合分布拆开，还可写成

```math
\mathrm{ELBO}=\mathbb E_q\log p_\theta(x\mid z)-D_{\rm KL}(q_\phi(z\mid x)\Vert p(z)).
```


**推导细节与进一步理解**

**为什么可以把一个难算的积分改成期望。** 在共同支持条件下，乘以再除以 $`q_\phi(z\mid x)`$ 不改变被积函数；这样做是为了把积分权重改成一个可采样的分布。Jensen 的方向由 $`\log`$ 是凹函数决定：$`\log\mathbb E[Y]\ge\mathbb E[\log Y]`$。这里 $`Y=p_\theta(x,z)/q_\phi(z\mid x)`$，不能把方向反过来。

下界差距也可以完全展开：

```math
\begin{aligned}
\log p_\theta(x)-\mathrm{ELBO}
&=\mathbb E_q\left[\log p_\theta(x)-\log p_\theta(x,z)+\log q_\phi(z\mid x)\right]\\
&=\mathbb E_q\left[\log\frac{q_\phi(z\mid x)}{p_\theta(z\mid x)}\right].
\end{aligned}
```

第二个等号利用了 $`p_\theta(x,z)=p_\theta(z\mid x)p_\theta(x)`$。因此等号条件中的参照对象是**真实后验**，而不是先验。先验 KL 出现在 ELBO 的内部，后验 KL 则表示 ELBO 与真实似然之间的差距，二者功能不同。

**考试作答顺序。** 先写边缘似然积分，再引入 $`q`$，接着正确使用 Jensen，最后说明后验 KL 的等号条件。只写“根据 Jensen 得证”而没有标明对哪个随机变量、在哪个分布下取期望，容易漏掉主要推导。

#### 第2题b 重参数化是什么以及为什么需要

**原题（PDF第2页）**

(b) (10 points) The reparameterization trick is applied to deduce the training objective of VAE. Describe what is the reparameterization trick in VAE and explain why we need it.

**详细解析**

对角高斯编码器输出 $`\mu_\phi(x),\sigma_\phi(x)`$，把采样改写为

```math
\boxed{\epsilon\sim\mathcal N(0,I),\qquad
z=\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon.}
```

于是重建项是

```math
\mathbb E_\epsilon\log p_\theta\!\left(x\mid\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon\right).
```

噪声分布与 $`\phi`$ 无关，固定抽到的噪声后，$`z`$ 对编码器参数是可导函数，可以按链式法则反向传播，获得路径梯度估计。直接把采样结果当成与参数无关的常数，会遗漏编码器通过分布改变样本的影响。

重参数化通常比 score function 估计更容易得到低方差梯度。并非所有“含采样的期望”都不能求导，也并非只能用这一种估计方式；这里采用它是为了高效训练 VAE。若编码器输出对数方差 $`r`$，则标准差应使用 $`e^{r/2}`$。


**推导细节与进一步理解**

**对编码器的梯度具体怎样流动。** 以重建项中的 $`h_\theta(z)=\log p_\theta(x\mid z)`$ 为例，在可交换微分与期望的条件下，

```math
\nabla_\phi\mathbb E_\epsilon h_\theta(z_\phi(\epsilon))
=\mathbb E_\epsilon\left[J_{z_\phi}(\epsilon)^\top\nabla_zh_\theta(z_\phi(\epsilon))\right],
```

而

```math
J_{z_\phi}(\epsilon)=J_{\mu_\phi}+\mathrm{diag}(\epsilon)J_{\sigma_\phi}.
```

所以梯度先经过解码器传到 $`z`$，再沿均值和标准差两条路径传到编码器。标准高斯噪声不需要对参数求导。若网络输出 log variance，标准差路径相应多一个 $`\tfrac12e^{r/2}`$ 因子。

**一次训练怎样使用。** 输入真实 $`x`$，编码得到 $`\mu,r`$，抽取一次 $`\epsilon`$，构造 $`z=\mu+e^{r/2}\odot\epsilon`$，解码后计算重建负对数似然，并加上高斯到先验的解析 KL，再对总损失反向传播。一次或少量采样就可以构成随机梯度估计，不需要精确计算所有潜变量的积分。

不能简单对固定采样得到的数值 $`z`$ 求导并期望自动恢复分布变化的影响。也不要说“概率密度不能求导”：密度通常可微，问题在于如何正确且有效地估计**含参数化采样的期望**的梯度。

### 第3题 GAN

#### 第3题a 训练过程与生成过程

**原题（PDF第2页）**

(a) (10 points) Given a dataset $`\mathcal D=\{x_i\}_{i\in[n]}`$, a discriminator $`f_D`$, and a generator $`f_G`$, briefly introduce the training and inference process of GAN.

**详细解析**

记 $`G=f_G,D=f_D`$。原始目标为

```math
\boxed{\min_G\max_D\big[
\mathbb E_{x\sim p_{\rm data}}\log D(x)
+\mathbb E_{z\sim p_z}\log(1-D(G(z)))\big].}
```

训练时交替执行：

1. 抽取真实样本 $`x`$ 和噪声 $`z`$，固定生成器，最大化判别器对真样本的 $`\log D(x)`$ 及假样本的 $`\log(1-D(G(z)))`$。
2. 固定判别器参数，更新生成器，让生成样本更易被判为真。可最小化原始 $`\mathbb E\log(1-D(G(z)))`$；实践中常最小化非饱和损失 $`-\mathbb E\log D(G(z))`$。

更新生成器时，判别器参数不变，但仍要让梯度经过判别器传到生成器。推理时只需 $`z\sim p_z`$ 后输出 $`G(z)`$，无需判别器。


**推导细节与进一步理解**

**一次交替更新的参数状态。** 判别器步骤把生成图像当作已生成的样本，只更新 $`f_D`$；生成器步骤把 $`f_D`$ 看成固定的可微评价函数，只更新 $`f_G`$。冻结判别器参数不等于把其输出从计算图中完全断开，否则生成器收不到“怎样改变图像才能更像真样本”的梯度。

对 $`m`$ 个真样本和 $`m`$ 个假样本，判别器实际最小化的是负的二元分类 log likelihood。生成器可用原始 minimax 损失，也可用非饱和损失，答题时应明确哪个是原始理论目标、哪个是常用训练替代。

**训练与推理的根本差别。** 训练用判别器提供反馈，但生成过程本身就是从简单先验采样噪声，再做一次生成器前向计算。标准 GAN 不需要为每个输出求似然，也不要求先寻找一个与真实图片对应的潜变量。

#### 第3题b KL 是 f 散度的特例

**原题（PDF第2页）**

(b) (10 points) Prove that the Kullback-Leibler (KL) divergence is a special case of f-divergence.

**详细解析**

按照题目给定的方向 $`D_f(p\Vert q)=\int q(x)f(p(x)/q(x))dx`$，选择

```math
\boxed{f(u)=u\log u,\quad u>0;\qquad f(0)=0.}
```

首先 $`f(1)=0`$，$`\lim_{u\downarrow0}u\log u=0`$，所以扩展到 0 后连续；其次 $`f''(u)=1/u>0`$，因此凸。代入得到

```math
D_f(p\Vert q)=\int q\frac pq\log\frac pq\,dx
=\int p\log\frac pq\,dx=D_{\rm KL}(p\Vert q).
```

若 $`p>0,q=0`$ 的集合有正的 $`p`$ 概率，则按扩展值约定 KL 为 $`+\infty`$，相应 f 散度也为 $`+\infty`$。

**易错点。** $`u\log u`$ 在 $`0<u<1`$ 时为负；生成函数不需要处处非负，需要的是凸性和 $`f(1)=0`$。非负的是积分形成的散度。


**推导细节与进一步理解**

**为什么选择 $`u\log u`$。** 题目定义的积分权重是 $`q(x)`$，而 KL 的积分权重是 $`p(x)`$。令 $`u=p/q`$，需要额外的因子 $`u`$ 把 $`q`$ 转成 $`p`$，再保留 $`\log u`$，因此自然想到 $`f(u)=u\log u`$。

若误取 $`f(u)=-\log u`$，代入后得到 $`\int q\log(q/p)=D_{\rm KL}(q\Vert p)`$，是反向 KL。这个对照能帮助检查散度的方向。

函数的非负性不是条件：例如 $`f(1/2)=-\tfrac12\log2<0`$。对积分取非负结论是因为在合适的支持条件下 $`\mathbb E_q[p/q]=1`$，凸性给出 $`\mathbb E_qf(p/q)\ge f(1)=0`$。需要处理支持缺失时，则使用扩展值定义，而不是随意省略分母为零的区域。

### 第4题 归一化流

#### 第4题a 变量替换与密度

**原题（PDF第3页）**

(a) (5 points) Let $`Z\in\mathbb R^d`$ be a random vector with probability density $`p_Z(z)`$. $`X`$ is a random vector given by $`X=g(Z)`$, where $`g(\cdot):\mathbb R^d\to\mathbb R^d`$ is a smooth function. Denote the probability density function of $`X`$ by $`p_X(x)`$. Use the multidimensional change of variables theorem to deduce the relationship between $`p_Z(z)`$ and $`p_X(x)`$.

**详细解析**

**题干条件。** 原卷只写 $`g`$ 光滑。归一化流的单一逆映射公式还需要 $`g`$ 可逆，并在考虑区域中满足非零 Jacobian 行列式。按本题归一化流语境补上这一必要条件。

对于 $`x=g(z)`$，体积变换为 $`dx=|\det J_g(z)|dz`$，概率质量守恒 $`p_X(x)dx=p_Z(z)dz`$，所以

```math
\boxed{p_X(x)=p_Z(g^{-1}(x))|\det J_{g^{-1}}(x)|
=\left.\frac{p_Z(z)}{|\det J_g(z)|}\right|_{z=g^{-1}(x)}.}
```

若 $`g`$ 非单射，但满足适当的局部可逆和原像条件，则需对原像求和：$`p_X(x)=\sum_{z:g(z)=x}p_Z(z)/|\det J_g(z)|`$。任意光滑映射甚至不保证 $`X`$ 存在通常的全维密度，例如常值映射。


**推导细节与进一步理解**

**从事件概率严格推导密度。** 对任意可测区域 $`A`$，

```math
\begin{aligned}
\Pr(X\in A)&=\Pr(Z\in g^{-1}(A))
=\int_{g^{-1}(A)}p_Z(z)dz\\
&=\int_Ap_Z(g^{-1}(x))|\det J_{g^{-1}}(x)|dx.
\end{aligned}
```

因为这个积分表示对任意 $`A`$ 都成立，就识别出了 $`p_X`$。逆函数定理给出 $`J_{g^{-1}}(x)=J_g(z)^{-1}`$，所以前向与逆向的行列式互为倒数；取绝对值处理方向翻转，不允许密度因负行列式变成负数。

**一维缩放检查。** 若 $`x=2z`$，一个小区间在变换后宽度扩大两倍，单位长度上的密度应减半，因此 $`p_X(x)=p_Z(x/2)/2`$。若误乘前向行列式 2，密度的总积分就会变成 4，而不是 1。这个例子适合检查变量替换的乘除方向。

#### 第4题b 显式设计可逆 MLP

**原题（PDF第3页）**

(b) (10 points) The normalizing flow is constructed by invertible networks. Now we consider the MLP case. Assume the neural network $`g(\cdot):\mathbb R^d\to\mathbb R^d`$ is given by $`g(x)=\sigma(Wx+b)`$, where $`\sigma`$ is the activation function, $`W\in\mathbb R^{d\times d}`$, $`b\in\mathbb R^d`$. Design an invertible $`g(x)`$ by adding constraints to its parameters and activation function. You should write down your choice of $`W,b,\sigma`$ explicitly.

**详细解析**

给出一个处处光滑、从 $`\mathbb R^d`$ 双射到 $`\mathbb R^d`$ 的设计：

```math
\boxed{W=L+\mathrm{diag}(e^{s_1},\ldots,e^{s_d}),\quad
b\in\mathbb R^d\text{ 任意},\quad \sigma(u)=\sinh u\text{ 逐元素作用}.}
```

其中 $`L`$ 是任意严格下三角矩阵。$`\det W=\prod_ie^{s_i}>0`$，所以线性部分可逆；$`\sinh`$ 严格递增、导数 $`\cosh u>0`$，值域是整个实数域，逆函数为 $`\mathrm{arsinh}`$。因此

```math
\boxed{g(z)=\sinh(Wz+b),\qquad
g^{-1}(x)=W^{-1}(\mathrm{arsinh}(x)-b).}
```

该设计的对数行列式是

```math
\log|\det J_g(z)|
=\sum_i s_i+\sum_i\log\cosh((Wz+b)_i).
```

ReLU 会把负半轴压成 0，不能作为可逆激活。$`\tanh`$ 虽然严格单调，但值域只有 $`(-1,1)`$；若要求整个 $`\mathbb R^d`$ 上的双射，需要说明其范围限制。LeakyReLU 在非零负斜率下也可构成几乎处处可微的流，但本答案选用 $`\sinh`$，以满足严格的光滑性。


**推导细节与进一步理解**

**逐层检查可逆性。** 线性映射 $`z\mapsto Wz+b`$ 的逆是 $`u\mapsto W^{-1}(u-b)`$；逐坐标映射 $`u\mapsto\sinh u`$ 的逆是 $`x\mapsto\mathrm{arsinh}x`$。把两者复合后，求逆必须先撤销最后的激活，再撤销线性变换，所以顺序为 $`W^{-1}(\mathrm{arsinh}x-b)`$，不能写成先乘 $`W^{-1}`$ 再对结果取 asinh。

非零对角线保证三角 $`W`$ 可逆：$`\det W=\prod_ie^{s_i}`$，任意有限 $`s_i`$ 下都为正。激活也需检查整个值域，$`\sinh`$ 连续严格递增，向两端分别趋于正负无穷，所以它确实是 $`\mathbb R`$ 到 $`\mathbb R`$ 的双射。

Jacobian 的链式法则给出

```math
J_g(z)=\mathrm{diag}(\cosh((Wz+b)_1),\ldots,\cosh((Wz+b)_d))W.
```

由行列式的乘法性得到前面的 log determinant。每个 $`\cosh`$ 都大于等于 1，因此激活不会产生零导数或奇异点。最简单的另一个合法答案是可逆 $`W`$ 加恒等激活，但它只是仿射流；本答案显式给出非线性的光滑设计。

#### 第4题c 训练目标与生成算法

**原题（PDF第3页）**

(c) (5 points) With your designed invertible MLP network in (b), briefly describe the training and inference algorithm of this model. At least, you need to write down the training objective and the inference algorithm.

**详细解析**

选 $`p_Z=\mathcal N(0,I)`$，数据为 $`x^{(1)},\ldots,x^{(N)}`$。对每个样本计算

```math
z^{(k)}=W^{-1}(\mathrm{arsinh}(x^{(k)})-b),
```

再最小化精确负对数似然：

```math
\boxed{\mathcal J(\theta)=\frac1N\sum_k\left[
-\log p_Z(z^{(k)})+\log|\det J_g(z^{(k)})|\right].}
```

对本题设计，$`\cosh(\mathrm{arsinh}x_i)=\sqrt{1+x_i^2}`$，故每个样本的损失还可显式写为

```math
\frac d2\log(2\pi)+\frac12\|z\|^2+\sum_i s_i+\frac12\sum_i\log(1+x_i^2).
```

通过梯度下降更新 $`L,s,b`$；求 $`W^{-1}v`$ 时实际可用三角求解，无需显式形成逆矩阵。生成时抽取 $`z\sim\mathcal N(0,I)`$，前向计算 $`x=\sinh(Wz+b)`$ 即可。单层的表达能力有限，多层可逆映射可以复合使用。


**推导细节与进一步理解**

**负对数似然的符号逐项核对。** 先由变量替换写 $`\log p_X=\log p_Z-\log|\det J_g|`$，再整体取负号，才得到 $`-\log p_Z+\log|\det J_g|`$。如果把第二项仍写成负号，就不再是精确似然。

生成模型在训练时的计算方向是数据 $`x\to z`$，因为需要评价真实样本概率；采样方向则是噪声 $`z\to x`$。同一个可逆网络因此需要同时提供前向和逆向，而不是分别训练两个任意的编码器与解码器。

当多个可逆层复合时，逆映射按反向层序执行，每层 log absolute determinant 相加。三角线性求解和逐元素 asinh 都能求导，所以损失可通过逆向计算图传回参数。若仅最小化 $`\|z\|^2`$ 而漏掉体积修正项，模型可能通过不恰当的尺度变换压缩所有数据；这不是最大似然训练。

### 第5题 扩散模型

以下统一使用期中记号：$`\alpha_t=1-\beta_t`$，$`\bar\alpha_t=\prod_{s=1}^t\alpha_s`$，$`\bar\alpha_0=1`$。

#### 第5题a 前向过程

**原题（PDF第3页）**

(a) (5 points) Let $`X_0`$ denote the data (e.g., clean images), and $`X_t`$ denote its noisy version at time $`t`$. Assume the time schedule of the DDPM model is $`\beta_t`$. Write down the forward process of the diffusion model.

**详细解析**

```math
\boxed{q(x_t\mid x_{t-1})=\mathcal N(\sqrt{\alpha_t}x_{t-1},\beta_tI),\qquad
x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{\beta_t}\epsilon_t,}
```

$`\epsilon_t\sim\mathcal N(0,I)`$ 相互独立且独立于 $`x_0`$。完整条件链为
$`q(x_{1:T}\mid x_0)=\prod_{t=1}^Tq(x_t\mid x_{t-1})`$。通常选择使 $`\bar\alpha_T`$ 很小的日程，令终态近似标准高斯。


**推导细节与进一步理解**

**为什么均值和噪声都要有平方根。** $`\beta_t`$ 在题目中是噪声的方差，所以噪声标准差为 $`\sqrt{\beta_t}`$；已有信号的系数是 $`\sqrt{1-\beta_t}`$。如果把它们写成 $`\beta_t`$ 与 $`1-\beta_t`$，方差递推会变成平方项，不再得到指定的边缘公式。

前向日程是预先给定的随机变换，不需要神经网络来预测要加什么噪声。随着步数增长，原图的条件均值缩放为 $`\sqrt{\bar\alpha_t}x_0`$，噪声方差增长到 $`1-\bar\alpha_t`$。只有累计信号量足够小时，才能把终态近似看作标准高斯；有限步且 $`\bar\alpha_T>0`$ 时，通常仍残留一点关于 $`x_0`$ 的信息。

这里的“前向”指数据到噪声的概率过程，和训练代码里神经网络的一次 forward 调用不是同一个概念。实际需要学习的是相反方向的去噪分布。

#### 第5题b 条件边缘分布

**原题（PDF第3页）**

(b) (5 points) Prove that the marginal distribution $`p(x_t\mid x_0)`$ is given by

```math
p(x_t\mid x_0)=\mathcal N(x_t\mid\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I),
\qquad\bar\alpha_t=\prod_{i=1}^t(1-\beta_i).
```

**详细解析**

归纳假设 $`x_{t-1}\mid x_0\sim\mathcal N(\sqrt{\bar\alpha_{t-1}}x_0,(1-\bar\alpha_{t-1})I)`$。由独立高斯的仿射组合，

```math
\mathbb E[x_t\mid x_0]=\sqrt{\alpha_t\bar\alpha_{t-1}}x_0=\sqrt{\bar\alpha_t}x_0,
```

```math
\mathrm{Cov}(x_t\mid x_0)
=[\alpha_t(1-\bar\alpha_{t-1})+\beta_t]I
=(1-\bar\alpha_t)I.
```

$`t=1`$ 直接成立，故

```math
\boxed{q(x_t\mid x_0)=\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I),\qquad
x_t\overset d=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon.}
```

这里的分布相等针对固定时刻；直接重采样各时刻的边缘不等于采样整条原链。


**推导细节与进一步理解**

**把第二步实际展开一次。** 由

```math
x_1=\sqrt{\alpha_1}x_0+\sqrt{\beta_1}\epsilon_1,
```

可得

```math
x_2=\sqrt{\alpha_2\alpha_1}x_0
+\sqrt{\alpha_2\beta_1}\epsilon_1+\sqrt{\beta_2}\epsilon_2.
```

所以条件均值是 $`\sqrt{\alpha_1\alpha_2}x_0`$，条件方差是 $`(\alpha_2\beta_1+\beta_2)I=(1-\alpha_1\alpha_2)I`$。后续步骤重复同样规律，得到累计乘积 $`\bar\alpha_t`$。

**证明的三部分缺一不可。** 独立高斯的线性组合保证分布类型；信号系数相乘给出均值；独立噪声方差相加给出协方差。只写出均值和协方差却不解释高斯性，或把标准差直接相加，都没有完整证明结论。

固定 $`x_0`$ 的条件分布是高斯，不表示数据总体的边缘 $`q(x_t)=\int q(x_t\mid x_0)q(x_0)dx_0`$ 在有限步时也必然是一个高斯；它一般仍是由数据分布混合出来的分布。

#### 第5题c 前向后验

**原题（PDF第3页）**

(c) (3 points) Prove that the posterior distribution conditioning on $`X_0`$ is given by

```math
p(x_{t-1}\mid x_0,x_t)=\mathcal N(x_{t-1}\mid\widetilde\mu_t(x_0,x_t),\widetilde\beta_t),
```

where

```math
\widetilde\mu_t(x_0,x_t)=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0
+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t,
```

```math
\widetilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t,
\qquad\alpha_t=1-\beta_t.
```

**详细解析**

设 $`y=x_{t-1}`$、$`A=\bar\alpha_{t-1}`$。当 $`t\ge2`$，Bayes 公式给出

```math
\log q(y\mid x_t,x_0)
=-\frac{\|x_t-\sqrt{\alpha_t}y\|^2}{2\beta_t}
-\frac{\|y-\sqrt A x_0\|^2}{2(1-A)}+C.
```

二次项的精度是

```math
P=\frac{\alpha_t}{\beta_t}+\frac1{1-A}
=\frac{1-\bar\alpha_t}{\beta_t(1-A)},
```

一次项系数向量是 $`B=\sqrt{\alpha_t}x_t/\beta_t+\sqrt A x_0/(1-A)`$。配方得均值 $`P^{-1}B`$、协方差 $`P^{-1}I`$，即

```math
\boxed{\widetilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t,}
```

```math
\boxed{\widetilde\mu_t(x_0,x_t)=
\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0
+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t.}
```

因此 $`q(x_{t-1}\mid x_t,x_0)=\mathcal N(\widetilde\mu_t,\widetilde\beta_t I)`$。原卷省略协方差中的 $`I`$，多维时应补上。$`t=1`$ 时已知 $`x_0`$，相应条件分布退化为 $`x_0`$ 处的点质量，公式给出零方差。


**推导细节与进一步理解**

**为什么前向精度项有 $`\alpha_t`$。** 似然里的平方是

```math
\|x_t-\sqrt{\alpha_t}y\|^2
=\|x_t\|^2-2\sqrt{\alpha_t}x_t^\top y+\alpha_t\|y\|^2.
```

除以 $`2\beta_t`$ 后，$`y`$ 的二次项系数因此是 $`\alpha_t/(2\beta_t)`$。另一个先验平方贡献 $`1/[2(1-A)]`$，精度相加才得到 $`P`$。这一步如果漏掉 $`\alpha_t`$，即使最终凭记忆写出正确公式，中间证明仍然不成立。

**配方后如何读出均值。** 对向量 $`y`$，

```math
-\tfrac12P\|y\|^2+B^\top y
=-\tfrac12P\|y-P^{-1}B\|^2+\tfrac12P^{-1}\|B\|^2.
```

第二项与 $`y`$ 无关，被吸收进归一化常数；第一项识别出均值 $`P^{-1}B`$ 和协方差 $`P^{-1}I`$。与某个只知道 $`x_t`$ 的去噪器不同，本题是在条件中同时给了真实 $`x_0`$，所以才有可解析的前向高斯后验。

#### 第5题d DDPM 的训练与推理

**原题（PDF第3页）**

(d) (7 points) Briefly describe the training and inference algorithm of DDPM.

**详细解析**

**训练。** 网络 $`\epsilon_\theta(x_t,t)`$ 预测噪声。重复抽取 $`x_0\sim p_{\rm data}`$、$`t\sim\mathrm{Uniform}\{1,\ldots,T\}`$、$`\epsilon\sim\mathcal N(0,I)`$，直接构造

```math
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,
```

最小化常用简化目标

```math
\boxed{L_{\rm simple}=\mathbb E_{x_0,t,\epsilon}\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2.}
```

这是常用的噪声均方误差目标；完整变分目标可以带不同时间权重和端点项，不能不加条件地把两者说成逐项完全相等。

**推理。** 从 $`x_T\sim\mathcal N(0,I)`$ 出发，对 $`t=T,T-1,\ldots,1`$ 计算

```math
\mu_\theta(x_t,t)=\frac1{\sqrt{\alpha_t}}
\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right),
```

```math
\boxed{x_{t-1}=\mu_\theta(x_t,t)+\sigma_t\xi,\qquad
\xi\sim\mathcal N(0,I)\ (t>1),\quad\xi=0\ (t=1).}
```

一种有效选择是 $`\sigma_t^2=\widetilde\beta_t`$，也有使用 $`\beta_t`$ 等方差设定的实现。最终输出 $`x_0`$。训练使用干净样本构造监督，生成时只给 $`x_t,t`$，不需要知道真实干净图像。

**推导细节与进一步理解**

**反向均值公式从哪里来。** 由直接加噪式可以形式上解出干净样本，并用模型预测替代未知噪声：

```math
\widehat x_0=\frac{x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)}{\sqrt{\bar\alpha_t}}.
```

把它代入解析前向后验均值

```math
\widetilde\mu_t(x_t,x_0)
=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0
+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t,
```

利用 $`\bar\alpha_t=\alpha_t\bar\alpha_{t-1}`$ 与
$`\beta_t+\alpha_t(1-\bar\alpha_{t-1})=1-\bar\alpha_t`$ 化简，正好得到前面的 $`\mu_\theta`$。因此噪声预测网络实际上给出了反向转移均值的一种参数化，而不是采样时还知道真实 $`x_0`$。

**为什么训练可以一步、采样却要多步。** 训练拥有真实 $`x_0`$，可以利用闭式边缘直接构造任意时间的监督样本；生成没有干净样本，只能从当前状态借助反向核逐步逼近数据。每一步的 $`\xi_t`$ 是新抽的采样噪声，与训练标签 $`\epsilon`$ 不是同一个变量；它的尺度由所选反向方差规定。

**MSE 的最优预测含义。** 最小化均方误差时，理想网络输出是条件期望 $`\mathbb E[\epsilon\mid x_t,t]`$。不同的干净样本和噪声可能产生同一个带噪观测，所以网络通常无法从单个 $`x_t`$ 唯一恢复当次真实噪声。把训练解释成学习这种条件规律，比解释成“每一步无误地减掉原噪声”更准确。

### 第1题 自回归模型

#### 第1题a 位置编码与时间编码

**原题（PDF第1页）**

(a) (5 points) Positional embedding is used in Transformers, while time embedding is used in diffusion models. Please explain their roles and provide a representative implementation for each.

**详细解析**

**Transformer 位置编码。** 它告诉网络 token 在序列中的位置，使模型能表达顺序或相对距离。没有位置相关机制的全连接自注意力是排列等变的，仅靠内容无法显式区分位置。代表实现是正弦编码：

```math
\mathrm{PE}(i,2k)=\sin\left(\frac{i}{10000^{2k/d}}\right),\qquad
\mathrm{PE}(i,2k+1)=\cos\left(\frac{i}{10000^{2k/d}}\right),
```

并令输入 $`h_i=\mathrm{TokenEmbed}(x_i)+\mathrm{PE}(i)`$。另一代表是 RoPE，旋转查询与键，使点积中的位置项依赖相对位移。

**扩散时间编码。** $`t`$ 指示当前扩散步及对应的噪声水平或信噪比。同一个网络需要在不同噪声阶段执行不同的去噪映射，因此应使用 $`\epsilon_\theta(x_t,t)`$ 而非只输入 $`x_t`$。

一种代表实现同样先生成正弦时间向量：

```math
e_t=(\sin(\omega_0t),\cos(\omega_0t),\ldots,\sin(\omega_{h-1}t),\cos(\omega_{h-1}t)),
```

再经 MLP 投影，在 U Net 残差块中加到特征上，或用于调节特征的缩放与偏置。频率可采用不同尺度，例如 $`\omega_k=10000^{-k/h}`$。噪声水平或 log SNR 也可作为编码输入。

两种编码都可能使用正弦形式，但含义不同：前者描述**序列内的位置**，后者描述**当前样本所处的去噪阶段**。时间编码不是图像像素的位置编码。


**推导细节与进一步理解**

**为什么两者都可能用正弦，却不表示同一件事。** 位置编码的输入是序列位置 $`i`$，同一条序列中不同 token 得到不同位置向量。扩散时间编码的输入是当前噪声时间 $`t`$；同一张带噪图像内的所有空间位置通常共享这个时间条件，但仍可以有各自的空间位置表示。

**代表实现怎样接到网络里。** 位置编码可直接与 token embedding 相加；时间编码通常先生成一组多频率正弦与余弦，再经 MLP 投影到当前网络块的通道数。以 U Net 特征 $`H\in\mathbb R^{C\times H_s\times W_s}`$ 为例，可以把时间向量投影成 $`C`$ 维后广播加到空间各点，或输出 $`\gamma(t),\beta(t)`$ 对特征做逐通道调制。

相同数值外观的 $`x_t`$ 在不同噪声水平下应当使用不同的去噪规律；不告诉网络时间，就把这些不同条件混在了一起。答题时分别写清“编码什么变量、解决什么歧义、如何注入网络”，比只列 sinusoidal 这个名字更完整。

#### 第1题b 自注意力计算与复杂度

**原题（PDF第2页）**

(b) (5 points) Suppose the sequence length is $`n`$ and the hidden dimension is $`d`$. Write down the calculation of a self-attention layer and discuss the computational complexity in terms of $`n`$ and $`d`$.

**详细解析**

对于 $`X\in\mathbb R^{n\times d}`$ 和 $`W_Q,W_K,W_V\in\mathbb R^{d\times d}`$，

```math
Q=XW_Q,\quad K=XW_K,\quad V=XW_V,\qquad
O=\mathrm{softmax}_{\rm row}\left(\frac{QK^\top}{\sqrt d}\right)V.
```

$`Q,K,V,O`$ 均为 $`n\times d`$；分数与概率矩阵为 $`n\times n`$；softmax 对每个查询所在的行、沿键的位置归一化。自回归模型还需因果掩码。

投影为 $`O(nd^2)`$，$`QK^\top`$ 和加权求和均为 $`O(n^2d)`$，softmax 为 $`O(n^2)`$。因此

```math
\boxed{\text{时间}=O(nd^2+n^2d),\qquad
\text{显式注意力存储}=O(n^2).}
```

含其他激活为 $`O(nd+n^2)`$，不计参数。输出投影若加入，额外为 $`O(nd^2)`$，总阶不变。不能默认所有模型均有 $`n\gg d`$ 而删掉投影项。


**推导细节与进一步理解**

**计算量为什么分成两项。** 投影矩阵乘法是在每个 token 上混合特征，$`n`$ 个位置各付出 $`d^2`$ 的成本；注意力计算则混合位置，$`n^2`$ 对位置各付出长度 $`d`$ 的点积成本。这两个维度的作用不同，所以完整答案应保留 $`nd^2+n^2d`$。

具体来说，三次投影约有 $`3nd^2`$ 级别的乘加操作，分数计算和加权汇总各有 $`n^2d`$ 级别操作。softmax 沿每行的键位置计算，对 $`n^2`$ 个分数做指数与归一化。若加入多头，只要头数固定、各头总维度仍为 $`d`$，这些主阶结论不变。

存储复杂度还需说明在存什么：题目中的显式分数或注意力概率矩阵为 $`n^2`$ 个元素，$`Q,K,V`$ 则各为 $`nd`$。使用 FlashAttention 可避免显式保留完整矩阵，但不会删掉标准稠密注意力所要求的全部位置交互。

#### 第1题c LayerNorm

**原题（PDF第2页）**

(c) (5 points) The data batch $`X`$ contains one sequence of four 2-dimensional vectors. For simplicity, we set the parameter $`\epsilon=0`$, the rescale mean $`\beta=0`$, and the rescale standard variation $`\gamma=1`$. Compute the output of layer normalization operating on $`X`$.

```math
X=\left[\begin{pmatrix}2\\1\end{pmatrix},
\begin{pmatrix}0\\2\end{pmatrix},
\begin{pmatrix}2\\0\end{pmatrix},
\begin{pmatrix}4\\1\end{pmatrix}\right].
```

**详细解析**

对每个二维 token 分别计算 $`\mu=(x_1+x_2)/2`$ 和
$`v=((x_1-\mu)^2+(x_2-\mu)^2)/2`$。给定 $`\epsilon=0,\gamma=1,\beta=0`$：

| 原 token | 均值 | 方差 | 归一化输出 |
|---|---:|---:|---|
| $`(2,1)`$ | $`1.5`$ | $`0.25`$ | $`(1,-1)`$ |
| $`(0,2)`$ | $`1`$ | $`1`$ | $`(-1,1)`$ |
| $`(2,0)`$ | $`1`$ | $`1`$ | $`(1,-1)`$ |
| $`(4,1)`$ | $`2.5`$ | $`2.25`$ | $`(1,-1)`$ |

因此

```math
\boxed{\mathrm{LN}(X)=
\left[\begin{pmatrix}1\\-1\end{pmatrix},
\begin{pmatrix}-1\\1\end{pmatrix},
\begin{pmatrix}1\\-1\end{pmatrix},
\begin{pmatrix}1\\-1\end{pmatrix}\right].}
```

LayerNorm 沿特征维计算，方差分母是 2；不是 BatchNorm，也不是无偏样本方差。


**推导细节与进一步理解**

**把第一个向量逐步算完。** 对 $`x=(2,1)^\top`$，先算均值 $`\mu=1.5`$，中心化结果是 $`(0.5,-0.5)`$；平方后是 $`(0.25,0.25)`$，平均得方差 0.25，开平方得标准差 0.5；最后逐分量相除得到 $`(1,-1)`$。第四个向量的中心化结果为 $`(1.5,-1.5)`$、标准差为 1.5，所以输出同样是 $`(1,-1)`$。

更一般地，二维向量 $`(a,b)`$ 的均值是 $`(a+b)/2`$，中心化后为 $`((a-b)/2,(b-a)/2)`$，方差为 $`(a-b)^2/4`$。当 $`a\ne b`$ 且 $`\epsilon=0`$，归一化结果就是

```math
\mathrm{LN}(a,b)=(\mathrm{sign}(a-b),-\mathrm{sign}(a-b)).
```

这说明本题各向量相差很大，输出仍只有两种形式并不奇怪。若两个分量完全相等，方差会是 0，本题指定 $`\epsilon=0`$ 时归一化没有定义；给定四个向量都避免了这一情况。实际 LayerNorm 通常保留正的 $`\epsilon`$，且可以学习 $`\gamma,\beta`$。

### 第2题 VAE

#### 第2题a ELBO 证明

**原题（PDF第2页）**

(a) (10 points) Let $`Z`$ be the latent variable. Let $`p(z)`$ be the prior distribution. Assume the conditional density function $`p_\theta(x\mid z)`$ is parametrized by a neural network $`\theta`$, the posterior distribution $`q_\phi(z\mid x)`$ is parametrized by a neural network $`\phi`$. Prove the variational lower bound

```math
\log p_\theta(x)\geq\mathbb E_{q_\phi(z\mid x)}
\left[\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\right].
```

**详细解析**

由 $`\log`$ 的凹性和 Jensen 不等式，

```math
\begin{aligned}
\log p_\theta(x)
&=\log\int q_\phi(z\mid x)\frac{p_\theta(x,z)}{q_\phi(z\mid x)}dz\\
&\ge\int q_\phi(z\mid x)\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}dz.
\end{aligned}
```

更明确地，

```math
\boxed{\log p_\theta(x)=\mathrm{ELBO}
+D_{\rm KL}(q_\phi(z\mid x)\Vert p_\theta(z\mid x)).}
```

KL 非负，得到下界；等号当且仅当近似后验与真实后验几乎处处相等。把联合分布拆分后，

```math
\mathrm{ELBO}=\mathbb E_q\log p_\theta(x\mid z)-D_{\rm KL}(q_\phi(z\mid x)\Vert p(z)).
```

这里默认所需的支持和可积条件成立。


**推导细节与进一步理解**

**为什么可以把一个难算的积分改成期望。** 在共同支持条件下，乘以再除以 $`q_\phi(z\mid x)`$ 不改变被积函数；这样做是为了把积分权重改成一个可采样的分布。Jensen 的方向由 $`\log`$ 是凹函数决定：$`\log\mathbb E[Y]\ge\mathbb E[\log Y]`$。这里 $`Y=p_\theta(x,z)/q_\phi(z\mid x)`$，不能把方向反过来。

下界差距也可以完全展开：

```math
\begin{aligned}
\log p_\theta(x)-\mathrm{ELBO}
&=\mathbb E_q\left[\log p_\theta(x)-\log p_\theta(x,z)+\log q_\phi(z\mid x)\right]\\
&=\mathbb E_q\left[\log\frac{q_\phi(z\mid x)}{p_\theta(z\mid x)}\right].
\end{aligned}
```

第二个等号利用了 $`p_\theta(x,z)=p_\theta(z\mid x)p_\theta(x)`$。因此等号条件中的参照对象是**真实后验**，而不是先验。先验 KL 出现在 ELBO 的内部，后验 KL 则表示 ELBO 与真实似然之间的差距，二者功能不同。

**考试作答顺序。** 先写边缘似然积分，再引入 $`q`$，接着正确使用 Jensen，最后说明后验 KL 的等号条件。只写“根据 Jensen 得证”而没有标明对哪个随机变量、在哪个分布下取期望，容易漏掉主要推导。

#### 第2题b VAE 重参数化及其作用

**原题（PDF第2页）**

(b) (10 points) The reparameterization trick is a key technique for training VAEs. Describe what is the reparameterization trick in VAE and explain why we need it.

**详细解析**

令 $`q_\phi(z\mid x)=\mathcal N(\mu_\phi(x),\mathrm{diag}(\sigma_\phi(x)^2))`$，改为

```math
\boxed{z=\mu_\phi(x)+\sigma_\phi(x)\odot\epsilon,\qquad\epsilon\sim\mathcal N(0,I).}
```

随机性放在与参数无关的 $`\epsilon`$ 上；给定一次噪声，$`z`$ 是参数的可导函数。因此可对 $`\mathbb E_\epsilon\log p_\theta(x\mid z(\phi,\epsilon))`$ 使用链式法则，将重建信号传回编码器，估计路径梯度。直接把采样结果当常数会漏掉分布参数的影响；score function 等替代方法虽可用，但通常有不同的方差性质。

编码器若输出 $`r=\log\sigma^2`$，实际采样应使用 $`z=\mu+e^{r/2}\odot\epsilon`$。


**推导细节与进一步理解**

**对编码器的梯度具体怎样流动。** 以重建项中的 $`h_\theta(z)=\log p_\theta(x\mid z)`$ 为例，在可交换微分与期望的条件下，

```math
\nabla_\phi\mathbb E_\epsilon h_\theta(z_\phi(\epsilon))
=\mathbb E_\epsilon\left[J_{z_\phi}(\epsilon)^\top\nabla_zh_\theta(z_\phi(\epsilon))\right],
```

而

```math
J_{z_\phi}(\epsilon)=J_{\mu_\phi}+\mathrm{diag}(\epsilon)J_{\sigma_\phi}.
```

所以梯度先经过解码器传到 $`z`$，再沿均值和标准差两条路径传到编码器。标准高斯噪声不需要对参数求导。若网络输出 log variance，标准差路径相应多一个 $`\tfrac12e^{r/2}`$ 因子。

**一次训练怎样使用。** 输入真实 $`x`$，编码得到 $`\mu,r`$，抽取一次 $`\epsilon`$，构造 $`z=\mu+e^{r/2}\odot\epsilon`$，解码后计算重建负对数似然，并加上高斯到先验的解析 KL，再对总损失反向传播。一次或少量采样就可以构成随机梯度估计，不需要精确计算所有潜变量的积分。

不能简单对固定采样得到的数值 $`z`$ 求导并期望自动恢复分布变化的影响。也不要说“概率密度不能求导”：密度通常可微，问题在于如何正确且有效地估计**含参数化采样的期望**的梯度。

### 第3题 GAN 与最优运输

#### 第3题a GAN 的训练目标

**原题（PDF第2页）**

(a) (10 points) Given a dataset $`\mathcal D=\{x_i\}_{i\in[n]}`$, a discriminator $`f_D`$, a generator $`f_G`$, explain the training objective of GAN.

**详细解析**

```math
\boxed{\min_G\max_D V(D,G)=
\mathbb E_{x\sim p_{\rm data}}\log D(x)
+\mathbb E_{z\sim p_z}\log(1-D(G(z))).}
```

判别器最大化 $`V`$，提高真样本的真假区分能力；生成器最小化第二项，让假样本被判为真。训练交替更新两者。为缓解原生成器目标在 $`D(G(z))\approx0`$ 时的梯度饱和，常把生成器损失改成 $`-\mathbb E_z\log D(G(z))`$；此时判别器仍使用原来的分类目标。


**推导细节与进一步理解**

**从分类问题读出目标的两个期望。** 对真样本，正确标签为 1，log likelihood 是 $`\log D(x)`$；对假样本，正确标签为 0，log likelihood 是 $`\log(1-D(G(z)))`$。判别器最大化二者之和，生成器则尝试让第二项降低，迫使假样本的真假判断向真实一侧移动。

真实分布在实际训练中用数据集经验分布近似：$`\mathbb E_{p_{\rm data}}\log D(x)\approx\frac1m\sum_i\log D(x_i)`$；生成期望用新采样的噪声近似。两个网络交替更新，生成器没有一个固定不变的分类器目标，而是在适应不断变化的判别器。

若写非饱和损失，应明确它是生成器的一种常用替代：最小化 $`-\log D(G(z))`$ 希望增大假样本真概率，同时避免原始目标在假样本真概率接近 0 时提供过小梯度。不能把该替代损失直接当成原始 minimax 目标的逐项代数变形。

#### 第3题b 广场舞队形切换怎样建模

**原题（PDF第2页）**

(b) (10 points) 广场上一群大爷大妈跳广场舞，队形在直线与圆圈间切换，考虑到参与者的年龄，平均移动距离应尽量短，作为老年歌舞团首席指挥的你，如何对该问题进行建模？

**详细解析**

**题意。** 每位参与者从直线队形的一个位置移动到圆圈队形的一个位置，要求平均移动距离最短。这是**最优运输／最小费用二分匹配**问题。

设人数 $`m`$，初始点 $`a_1,\ldots,a_m\in\mathbb R^2`$，目标圆圈上准备好的 $`m`$ 个位置为 $`b_1,\ldots,b_m`$。把“谁去哪个终点”表示为排列 $`\pi`$，目标是

```math
\boxed{\min_{\pi\in S_m}\frac1m\sum_{i=1}^m\|a_i-b_{\pi(i)}\|_2.}
```

也可写成运输线性规划。令 $`\gamma_{ij}`$ 表示从 $`a_i`$ 运到 $`b_j`$ 的概率质量，

```math
\boxed{\min_{\gamma\ge0}\sum_{i,j}\gamma_{ij}\|a_i-b_j\|_2,\qquad
\sum_j\gamma_{ij}=\frac1m,\quad\sum_i\gamma_{ij}=\frac1m.}
```

行约束保证每个初始位置的质量都被运走，列约束保证每个目标位置收到恰当质量。$`m\gamma`$ 为双随机矩阵；根据 Birkhoff 定理，线性目标存在一个排列矩阵形式的最优解，因此可得到“每人只去一个位置”的安排。可用匈牙利算法或其他指派问题算法求解。

定义经验分布 $`P=\frac1m\sum_i\delta_{a_i}`$、$`Q=\frac1m\sum_j\delta_{b_j}`$，上述最小平均欧氏距离就是

```math
W_1(P,Q)=\inf_{\gamma\in\Pi(P,Q)}\mathbb E_{(a,b)\sim\gamma}\|a-b\|_2.
```

题意是距离而非距离平方，所以直接对应 $`W_1`$；若改成平方距离，得到的是 $`W_2^2`$，最优匹配也可能改变。WGAN 使用的 Wasserstein 思想正是通过地面距离衡量把一个分布变成另一个分布的代价。

若圆圈的圆心、半径、整体转角尚未指定，可把它们也作为外层变量；原题没有给坐标，要求是建模，无从计算唯一的数值匹配。直线路径在无障碍平面上最短；若另要求不碰撞、速度受限或控制最长个人距离，需要另外加入约束，原题的平均距离目标本身不包含这些条件。


**推导细节与进一步理解**

**为什么目标是匹配而不是逐人贪心。** 每个人选择某个目标位置后，其他人就不能再占用同一个位置；这些决策相互耦合，所以应当联合优化排列。一般指派问题中，先挑当前最近的一对再继续，未必使总距离最小。

例如一维出发点 $`0,3`$、终点 $`2,100`$，所有边中最近的一对是 $`3\to2`$，距离 1；若先固定它，另一个人只能走 $`0\to100`$，总距离 101。联合选择 $`0\to2`$、$`3\to100`$ 的总距离为 $`2+97=99`$，更小。这个小例子说明“每次选最近”不能替代全局运输优化。

**为什么线性规划不会要求把一个人拆成几份。** 数学上允许连续 $`\gamma_{ij}`$ 是一个方便的松弛。若 $`m\gamma=\sum_k\lambda_kP_k`$ 是排列矩阵的凸组合，则其成本也是这些完整匹配成本的加权平均。至少有一个排列的成本不大于该平均值；因此总存在一个不拆分人的最优排列解。

**怎样与 WGAN 联系。** 直线分布和圆圈分布即使互不重合，也能通过真实的几何移动定义有限运输成本。与只比较同一点概率比值的散度不同，这个成本会反映两套队形在空间上究竟相隔多远。此题需要写的是这个运输目标及其边缘约束，不能只写“使用 Wasserstein 距离”而不说明运什么、成本是什么、可行方案受什么限制。

### 第4题 归一化流

#### 第4题a 变量替换

**原题（PDF第3页）**

(a) (10 points) Let $`Z\in\mathbb R^d`$ be a random vector with probability density $`p_Z(z)`$. $`X`$ is a random vector given by $`X=g(Z)`$, where $`g(\cdot):\mathbb R^d\to\mathbb R^d`$ is a smooth and invertible function. Denote the probability density function of $`X`$ by $`p_X(x)`$. Use the multidimensional change of variables theorem to deduce the relationship between $`p_Z(z)`$ and $`p_X(x)`$.

**详细解析**

按可逆流通常采用的 Jacobian 非奇异条件，$`x=g(z)`$ 的概率质量守恒给出

```math
p_X(x)dx=p_Z(z)dz,\qquad dx=|\det J_g(z)|dz.
```

所以

```math
\boxed{p_X(x)=p_Z(g^{-1}(x))|\det J_{g^{-1}}(x)|
=\frac{p_Z(z)}{|\det J_g(z)|},\quad z=g^{-1}(x).}
```

取对数得到 $`\log p_X(x)=\log p_Z(z)-\log|\det J_g(z)|`$。注意前向映射的行列式应当除掉，而逆映射的行列式应当乘上。


**推导细节与进一步理解**

**从事件概率严格推导密度。** 对任意可测区域 $`A`$，

```math
\begin{aligned}
\Pr(X\in A)&=\Pr(Z\in g^{-1}(A))
=\int_{g^{-1}(A)}p_Z(z)dz\\
&=\int_Ap_Z(g^{-1}(x))|\det J_{g^{-1}}(x)|dx.
\end{aligned}
```

因为这个积分表示对任意 $`A`$ 都成立，就识别出了 $`p_X`$。逆函数定理给出 $`J_{g^{-1}}(x)=J_g(z)^{-1}`$，所以前向与逆向的行列式互为倒数；取绝对值处理方向翻转，不允许密度因负行列式变成负数。

**一维缩放检查。** 若 $`x=2z`$，一个小区间在变换后宽度扩大两倍，单位长度上的密度应减半，因此 $`p_X(x)=p_Z(x/2)/2`$。若误乘前向行列式 2，密度的总积分就会变成 4，而不是 1。这个例子适合检查变量替换的乘除方向。

#### 第4题bi MAF 前向 Jacobian 的对数行列式

**原题（PDF第3页）**

Let $`z\in\mathbb R^d`$ be a latent variable drawn from a standard Gaussian $`p_Z(z)=\mathcal N(0,I)`$. Consider a single-layer **Masked Autoregressive Flow (MAF)** defined by a map $`f:\mathbb R^d\to\mathbb R^d`$ that transforms $`z`$ into $`x=f(z)`$, with components

```math
x_i=\mu_i(x_{1:i-1})+\sigma_i(x_{1:i-1})z_i,\qquad i=1,\ldots,d,
```

where $`\mu_i(\cdot)`$ and $`\sigma_i(\cdot)>0`$ are outputs of a masked autoregressive network.

(i) (5 points) Derive the log-determinant of the Jacobian, $`\log|\det J_f(z)|`$. Here $`J_f(z)`$ denotes the Jacobian matrix of $`f:\mathbb R^d\to\mathbb R^d`$ at the point $`z=(z_1,\ldots,z_d)^\top`$, whose $`(i,j)`$-th entry is

```math
(J_f(z))_{ij}=\frac{\partial f_i(z)}{\partial z_j}.
```

**详细解析**

给定

```math
x_i=\mu_i(x_{1:i-1})+\sigma_i(x_{1:i-1})z_i,\qquad\sigma_i>0.
```

先归纳观察 $`x_i`$ 只依赖 $`z_1,\ldots,z_i`$，所以对 $`j>i`$，$`\partial x_i/\partial z_j=0`$。又因为 $`x_{1:i-1}`$ 不依赖 $`z_i`$，

```math
\frac{\partial x_i}{\partial z_i}=\sigma_i(x_{1:i-1}).
```

因此 $`J_f`$ 是下三角矩阵，虽然对角线以下一般不为 0，其行列式仍然仅为对角线乘积：

```math
\boxed{\det J_f(z)=\prod_{i=1}^d\sigma_i(x_{1:i-1}),\qquad
\log|\det J_f(z)|=\sum_{i=1}^d\log\sigma_i(x_{1:i-1}).}
```


**推导细节与进一步理解**

**用三维例子看清三角结构。** 依赖顺序是 $`x_1=f_1(z_1)`$，$`x_2=f_2(z_1,z_2)`$，$`x_3=f_3(z_1,z_2,z_3)`$，所以

```math
J_f=\begin{pmatrix}
\sigma_1&0&0\\
*&\sigma_2&0\\
*&*&\sigma_3
\end{pmatrix}.
```

星号一般不为零：例如 $`\mu_2=ax_1`$、$`\sigma_2=c`$ 时，$`\partial x_2/\partial z_1=a\sigma_1`$。只有右上角为零，不是整个 Jacobian 都对角。

对角线之所以恰好等于 $`\sigma_i`$，是因为 $`\mu_i`$ 和 $`\sigma_i`$ 只依赖已经生成的 $`x_{<i}`$，而这些量不依赖当前的 $`z_i`$。因此对 $`z_i`$ 求导时它们像常数，但对更早的 $`z_j`$ 求导时不能当常数。

三角矩阵行列式的计算不需要求出星号，所以复杂的自回归依赖仍可给出简单的精确体积项。这正是这一结构用于归一化流的主要优势。

#### 第4题bii 逆映射与 log density

**原题（PDF第3页）**

(ii) (2 points) Using the change-of-variables formula, derive the log-density of the transformed variable $`x`$:

```math
\log p_X(x)=\log p_Z(f^{-1}(x))-\log|\det J_f(z)|.
```

Explicitly write out $`f^{-1}`$ for this flow.

**详细解析**

给定完整的 $`x`$，每一维的逆映射是

```math
\boxed{z_i=[f^{-1}(x)]_i=\frac{x_i-\mu_i(x_{1:i-1})}{\sigma_i(x_{1:i-1})}.}
```

因为 $`p_Z=\mathcal N(0,I)`$，

```math
\boxed{\log p_X(x)=-\frac d2\log(2\pi)
-\frac12\sum_i\left(\frac{x_i-\mu_i(x_{1:i-1})}{\sigma_i(x_{1:i-1})}\right)^2
-\sum_i\log\sigma_i(x_{1:i-1}).}
```

这里加减号由第4题a决定。注意各 $`\mu_i,\sigma_i`$ 的输入是已知的数据前缀 $`x_{1:i-1}`$。


**推导细节与进一步理解**

**也可以从条件概率独立得到密度。** 给定 $`x_{<i}`$，第 $`i`$ 维是标准高斯的平移缩放，所以

```math
p(x_i\mid x_{<i})=\frac1{\sigma_i(x_{<i})}\,
\varphi\left(\frac{x_i-\mu_i(x_{<i})}{\sigma_i(x_{<i})}\right),
```

其中 $`\varphi`$ 是标准一维正态密度。链式分解 $`p_X(x)=\prod_i p(x_i\mid x_{<i})`$，再取对数，就会得到与变量替换完全相同的 $`-\frac12\sum_i z_i^2-\sum_i\log\sigma_i`$，并有 $`-\frac d2\log(2\pi)`$ 常数。

这也解释了逆映射为何简单：评价真实样本时，每个 $`x_i`$ 和前缀都已经给定，只需减均值、除标准差。$`\sigma_i>0`$ 保证这个除法合法，也让 log absolute determinant 可直接写成普通 $`\log\sigma_i`$；如果网络输出无约束数值，通常先用指数等正值变换生成尺度。

#### 第4题biii 为什么 MLE 训练能按维度并行

**原题（PDF第3页）**

(iii) (3 points) Explain why training the MAF under the maximum-likelihood objective can be performed in parallel across all dimensions.

**详细解析**

最大似然训练时整个真实向量 $`x`$ 已知。掩码自回归网络可以在一次并行前向计算中输出所有 $`\mu_i(x_{<i}),\sigma_i(x_{<i})`$；掩码限制依赖关系，并不要求程序真的一个维度一个维度调用网络。随后计算全部 $`z_i`$ 和 log density 都是逐元素运算与求和，可以并行并反向传播。

生成时则不同：给定 $`z`$，要先生成 $`x_1`$，才能得到依赖它的 $`x_2`$，依次类推。**本题所定义的 MAF 是密度计算和训练并行、采样按维度串行。** 不应把它与方向相反的 IAF 混淆。


**推导细节与进一步理解**

**网络依赖的“自回归”不等于执行的“串行”。** 训练时已经知道整条 $`x`$，所以网络可以把所有前缀所需的信息一次输入，靠固定掩码阻断不合法的依赖。输出层同时产出所有维度的均值与尺度，随后 $`z_i`$ 的计算、平方及求和都可以并行。

采样时则未知 $`x`$：即使整条 $`z`$ 已经抽好，第 2 维的参数仍要等 $`x_1`$，第 3 维的参数要等 $`x_{1:2}`$。因此在本题给出的 $`z\to x`$ 方向中，生成维度之间存在真实的顺序依赖。

这里说的并行是各维度的计算可以同时进行，并非整个神经网络所有层可以同时执行。训练还需正常的前向层序与反向传播，也需保证掩码确实只允许 $`x_{<i}`$，否则所写的条件密度就不再对应题设流。

### 第5题 扩散模型

以下 $`\alpha_t=1-\beta_t`$，$`\bar\alpha_t=\prod_{r=1}^t\alpha_r`$。

#### 第5题a 前向加噪过程

**原题（PDF第4页）**

(a) (5 points) Let $`X_0`$ denote the data (e.g., clean images), and $`X_t`$ denote its noisy version at time $`t`$. Assume the time schedule of the DDPM model is $`\beta_t`$. Write down the forward process of the diffusion model.

**详细解析**

```math
\boxed{x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{\beta_t}\epsilon_t,\quad
q(x_t\mid x_{t-1})=\mathcal N(\sqrt{\alpha_t}x_{t-1},\beta_tI),}
```

$`\epsilon_t\sim\mathcal N(0,I)`$ 相互独立并独立于 $`x_0`$。完整过程是 $`q(x_{1:T}\mid x_0)=\prod_{t=1}^Tq(x_t\mid x_{t-1})`$。


**推导细节与进一步理解**

**为什么均值和噪声都要有平方根。** $`\beta_t`$ 在题目中是噪声的方差，所以噪声标准差为 $`\sqrt{\beta_t}`$；已有信号的系数是 $`\sqrt{1-\beta_t}`$。如果把它们写成 $`\beta_t`$ 与 $`1-\beta_t`$，方差递推会变成平方项，不再得到指定的边缘公式。

前向日程是预先给定的随机变换，不需要神经网络来预测要加什么噪声。随着步数增长，原图的条件均值缩放为 $`\sqrt{\bar\alpha_t}x_0`$，噪声方差增长到 $`1-\bar\alpha_t`$。只有累计信号量足够小时，才能把终态近似看作标准高斯；有限步且 $`\bar\alpha_T>0`$ 时，通常仍残留一点关于 $`x_0`$ 的信息。

这里的“前向”指数据到噪声的概率过程，和训练代码里神经网络的一次 forward 调用不是同一个概念。实际需要学习的是相反方向的去噪分布。

#### 第5题b 边缘分布证明

**原题（PDF第4页）**

(b) (5 points) Prove that the marginal distribution $`p_t(x_t\mid x_0)`$ is given by

```math
p_t(x_t\mid x_0)=\mathcal N(x_t\mid\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I),
\qquad\bar\alpha_t=\prod_{i=1}^t(1-\beta_i).
```

**详细解析**

展开递推可得

```math
x_t=\sqrt{\bar\alpha_t}x_0+
\sum_{r=1}^t\sqrt{\beta_r\prod_{s=r+1}^t\alpha_s}\,\epsilon_r.
```

固定 $`x_0`$ 后，独立高斯的线性组合仍是高斯；均值为 $`\sqrt{\bar\alpha_t}x_0`$，协方差中的标量是

```math
\begin{aligned}
\sum_{r=1}^t\beta_r\prod_{s=r+1}^t\alpha_s
&=\sum_{r=1}^t\left(\prod_{s=r+1}^t\alpha_s-\prod_{s=r}^t\alpha_s\right)\\
&=1-\bar\alpha_t.
\end{aligned}
```

因此

```math
\boxed{q(x_t\mid x_0)=\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I).}
```

也可以用一步均值和方差的归纳证明。必须使用独立性，且方差中不能把 $`\sqrt{1-\bar\alpha_t}`$ 和 $`1-\bar\alpha_t`$ 混为一谈。


**推导细节与进一步理解**

**把第二步实际展开一次。** 由

```math
x_1=\sqrt{\alpha_1}x_0+\sqrt{\beta_1}\epsilon_1,
```

可得

```math
x_2=\sqrt{\alpha_2\alpha_1}x_0
+\sqrt{\alpha_2\beta_1}\epsilon_1+\sqrt{\beta_2}\epsilon_2.
```

所以条件均值是 $`\sqrt{\alpha_1\alpha_2}x_0`$，条件方差是 $`(\alpha_2\beta_1+\beta_2)I=(1-\alpha_1\alpha_2)I`$。后续步骤重复同样规律，得到累计乘积 $`\bar\alpha_t`$。

**证明的三部分缺一不可。** 独立高斯的线性组合保证分布类型；信号系数相乘给出均值；独立噪声方差相加给出协方差。只写出均值和协方差却不解释高斯性，或把标准差直接相加，都没有完整证明结论。

固定 $`x_0`$ 的条件分布是高斯，不表示数据总体的边缘 $`q(x_t)=\int q(x_t\mid x_0)q(x_0)dx_0`$ 在有限步时也必然是一个高斯；它一般仍是由数据分布混合出来的分布。

#### 第5题c DDPM 训练和推理

**原题（PDF第4页）**

(c) (10 points) Briefly describe the training and inference algorithm of DDPM.

**详细解析**

训练时随机抽取真实数据 $`x_0`$、时间 $`t`$、噪声 $`\epsilon\sim\mathcal N(0,I)`$，直接构造

```math
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon.
```

使用带时间条件的网络预测噪声，最小化常用简化损失

```math
\boxed{L_{\rm simple}=\mathbb E\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2.}
```

推理时从 $`x_T\sim\mathcal N(0,I)`$ 开始，依次执行 $`t=T,\ldots,1`$：

```math
\boxed{x_{t-1}=\frac1{\sqrt{\alpha_t}}
\left[x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right]
+\sigma_t\xi_t.}
```

$`t>1`$ 时独立采样 $`\xi_t\sim\mathcal N(0,I)`$，最后一步取 $`\xi_1=0`$。例如选择
$`\sigma_t^2=\widetilde\beta_t=\beta_t(1-\bar\alpha_{t-1})/(1-\bar\alpha_t)`$。输出最终 $`x_0`$。起始标准高斯近似要求终端信号量 $`\bar\alpha_T`$ 足够小。

训练无需顺序执行 $`t`$ 次加噪；推理需要使用反向采样器逐步去噪。这里的常用简化 MSE 与完整负 ELBO 的时间加权形式应加以区分。


**推导细节与进一步理解**

**反向均值公式从哪里来。** 由直接加噪式可以形式上解出干净样本，并用模型预测替代未知噪声：

```math
\widehat x_0=\frac{x_t-\sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t,t)}{\sqrt{\bar\alpha_t}}.
```

把它代入解析前向后验均值

```math
\widetilde\mu_t(x_t,x_0)
=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0
+\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t,
```

利用 $`\bar\alpha_t=\alpha_t\bar\alpha_{t-1}`$ 与
$`\beta_t+\alpha_t(1-\bar\alpha_{t-1})=1-\bar\alpha_t`$ 化简，正好得到前面的 $`\mu_\theta`$。因此噪声预测网络实际上给出了反向转移均值的一种参数化，而不是采样时还知道真实 $`x_0`$。

**为什么训练可以一步、采样却要多步。** 训练拥有真实 $`x_0`$，可以利用闭式边缘直接构造任意时间的监督样本；生成没有干净样本，只能从当前状态借助反向核逐步逼近数据。每一步的 $`\xi_t`$ 是新抽的采样噪声，与训练标签 $`\epsilon`$ 不是同一个变量；它的尺度由所选反向方差规定。

**MSE 的最优预测含义。** 最小化均方误差时，理想网络输出是条件期望 $`\mathbb E[\epsilon\mid x_t,t]`$。不同的干净样本和噪声可能产生同一个带噪观测，所以网络通常无法从单个 $`x_t`$ 唯一恢复当次真实噪声。把训练解释成学习这种条件规律，比解释成“每一步无误地减掉原噪声”更准确。

#### 额外题1 二维高斯自回归的联合似然

附解给出 $`x_1\sim\mathcal N(0,1)`$、$`x_2\mid x_1\sim\mathcal N(ax_1,1)`$。由链式分解，

```math
p(x_1,x_2)=p(x_1)p(x_2\mid x_1)
=\frac1{2\pi}\exp\left[-\frac{x_1^2+(x_2-ax_1)^2}{2}\right],
```

```math
\boxed{\log p(x_1,x_2)=-\log(2\pi)-\frac12x_1^2-\frac12(x_2-ax_1)^2.}
```

可写 $`x_1=\epsilon_1,x_2=a\epsilon_1+\epsilon_2`$，于是联合分布为零均值高斯，协方差
$`\begin{pmatrix}1&a\\a&a^2+1\end{pmatrix}`$，其行列式为 1，与密度的归一化常数相符。

#### 额外题2 一般线性加噪过程

若 $`x_t=a_tx_{t-1}+b_t\epsilon_t`$，其中 $`a_t,b_t`$ 是确定系数，噪声独立标准高斯，则

```math
\boxed{x_t\mid x_0\sim\mathcal N\left(
\left(\prod_{r=1}^ta_r\right)x_0,
\left[\sum_{r=1}^tb_r^2\prod_{s=r+1}^ta_s^2\right]I\right).}
```

这由展开递推与独立噪声方差相加直接得到。取 $`a_t=\sqrt{1-\beta_t}`$、$`b_t=\sqrt{\beta_t}`$ 就得到 DDPM。若要求每个时刻的均值和方差都与指定 DDPM 一致，$`a_t>0`$ 时均值固定了这个 $`a_t`$，方差递推要求 $`b_t^2=\beta_t`$；噪声系数的正负不影响高斯分布。

#### 额外题3 给定反向方差时求线性系数

考虑自己构造的反向核

```math
x_{t-1}=kx_0+mx_t+\sigma\xi,\qquad
\xi\sim\mathcal N(0,I),\quad\xi\perp x_t\mid x_0.
```

要求它把 $`x_t\mid x_0\sim\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I)`$ 映到所需的前一时刻边缘，则比较均值与方差：

```math
k+m\sqrt{\bar\alpha_t}=\sqrt{\bar\alpha_{t-1}},\qquad
m^2(1-\bar\alpha_t)+\sigma^2=1-\bar\alpha_{t-1}.
```

因此必须满足 $`0\le\sigma^2\le1-\bar\alpha_{t-1}`$，并有

```math
\boxed{m=\pm\sqrt{\frac{1-\bar\alpha_{t-1}-\sigma^2}{1-\bar\alpha_t}},\qquad
k=\sqrt{\bar\alpha_{t-1}}-m\sqrt{\bar\alpha_t}.}
```

匹配边缘本身不能保证这是原 DDPM 链的真实后验，因为时刻间的联合相关结构也需要匹配。若选

```math
\sigma^2=\widetilde\beta_t=\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t
```

并取 $`m`$ 的**正根**，则

```math
m=\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t},\qquad
k=\frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t},
```

恰好恢复真实前向后验的均值和方差。选同方差的负根虽然仍可匹配边缘，却不会恢复原链的正向相关结构。完整后验配方证明见 [第四次作业第2题](作业4_扩散模型_解析.md)。

#### 关键错误 后验精度漏乘单步信号系数

民间 PDF 第 7 页及源码第5题c把二次项精度写成

```math
\frac1{\widetilde\beta_t}=\frac1{\beta_t}+\frac1{1-\bar\alpha_{t-1}}.
```

正确式应当是

```math
\boxed{\frac1{\widetilde\beta_t}=\frac{\alpha_t}{\beta_t}+\frac1{1-\bar\alpha_{t-1}}.}
```

原因是 $`\|x_t-\sqrt{\alpha_t}x_{t-1}\|^2`$ 展开时，$`x_{t-1}^2`$ 的系数为 $`\alpha_t`$。原文随后写出的最终方差公式是正确的，但它不能由其错误的中间式推出。

例如 $`\beta_t=0.2,\alpha_t=0.8,\bar\alpha_{t-1}=0.6`$ 时，正确精度为 $`0.8/0.2+1/0.4=6.5`$，后验方差为 $`1/6.5\approx0.153846`$；漏乘后变成 $`1/0.2+1/0.4=7.5`$，对应方差约 $`0.133333`$。

#### 其他表述需要收紧

民间答案把严格单调直接等同于 $`\mathbb R`$ 上的双射；严格单调只保证对其像集可逆，仍需检查值域。LeakyReLU 的非零负斜率可保证双射，但在 0 不光滑；如果严格按光滑题干作答，可以采用本地解析给出的 $`\sinh`$ 激活。

其 f 散度证明列表中的“non negative”若指 $`f(u)`$ 则不成立，因为 $`u\log u<0`$ 对 $`0<u<1`$ 成立。生成函数无需处处非负。

这份笔记的正文还存在几处会影响答题的错误；以下是对涉及公式和定义的补充解释。

#### Top k 与 Top p 按截断后概率采样

第 9 页把 top k 说成在前 $`k`$ 个词中均匀采样，把 top p 说成挑单个概率大于阈值的词再均匀采样；两者都不准确。

对概率 $`p_1,\ldots,p_V`$，top k 保留概率最大的 $`k`$ 个候选组成集合 $`A`$；top p 按概率降序取累计概率达到阈值 $`p`$ 的最小前缀集合 $`A`$。两者随后通常均按

```math
\boxed{p'_i=\frac{p_i\mathbf1_{i\in A}}{\sum_{j\in A}p_j}}
```

采样，保留相对概率，而非均匀采样。例如 $`(0.50,0.30,0.15,0.05)`$ 在 top k 的 $`k=2`$ 下变成 $`(0.625,0.375,0,0)`$；top p 的阈值 0.8 也会保留前两个。[原论文第 3 节](https://arxiv.org/html/1904.09751v2#S3)

#### KV cache 不把完整生成降为线性

第 9 页声称 KV cache 可把注意力推理时间降到 $`O(n)`$，这需要改成：**在已有长度为 $`n`$ 的缓存时，处理一个新 token 的注意力交互是 $`O(nd)`$**；生成 $`n`$ 个 token 时累计交互仍为 $`O(n^2d)`$。它避免重算旧 token 的键值及相关前缀计算，并不让每个新查询免于读取历史键值。同页将 $`AV`$ 的乘法记为 $`O(n)`$ 也不正确，稠密实现应为 $`O(n^2d)`$。

#### VQ VAE 选最近码字并区分两类损失

第 4 页正文出现 argmax，但最近邻应为

```math
k=\arg\min_j\|z_e-e_j\|_2^2.
```

直通表示 $`z_{\rm ST}=z_e+\mathrm{stopgrad}(e_k-z_e)`$ 在前向取码字，反向将重建梯度传给编码器。经典损失写为

```math
\boxed{L=L_{\rm recon}
+\|\mathrm{stopgrad}(z_e)-e_k\|_2^2
+\beta\|z_e-\mathrm{stopgrad}(e_k)\|_2^2.}
```

第二项更新码本，第三项为带权重 $`\beta`$ 的 commitment 项，更新编码器。笔记文字把这两项的标准系数位置交换，且有处遗漏平方；配套截图反而展示了标准方向。应以梯度流向识别，而不只靠损失的名字。[VQ VAE 原论文第 3.2 节](https://arxiv.org/html/1711.00937v2#S3.SS2)

#### VAE 先验与重参数化的准确含义

第 2 至 3 页将问题解释成“高斯分布不能求导”“$`p(z)`$ 是复杂向量”或固定 $`z`$ 只有少量 $`x`$ 的似然非零，均不能作为 VAE 的一般前提。通常先验 $`p(z)`$ 是容易采样和计算的标准高斯；困难来自 $`p_\theta(x)=\int p(z)p_\theta(x\mid z)dz`$ 中高维、非线性的积分和后验推断。高斯密度可对参数求导，重参数化提供的是对期望的路径梯度；高斯解码似然通常有全空间支持。

正确的基本关系见作业1第1题和第3题。无需上述支持稀疏假设就能推导 ELBO。

#### 正交矩阵的行列式及逆运算成本

第 15 页应写成 $`A^{-1}=A^\top`$、$`|\det A|=1`$，而非总有 $`\det A=1`$。例如 $`A=\mathrm{diag}(-1,1)`$ 为正交矩阵，但行列式是 $`-1`$。因此它的 log absolute determinant 为 0。

普通稠密三角矩阵的**求解** $`Az=b`$ 可在 $`O(d^2)`$ 完成；不应把它误写成完整求逆矩阵只需 $`O(d^2)`$。正交矩阵转置易得，但对稠密矩阵执行 $`A^\top x`$ 通常仍需 $`O(d^2)`$ 运算。

#### 扩散边缘与似然上界

第 16 页的“最终都会达到标准高斯”在有限步中应理解为日程使累计信号量很小时的近似；除非满足特殊条件，有限步不恰好等于标准高斯。第 17 页的目标 $`\mathbb E[-\log p_\theta(x_0)]`$ 是负对数似然的期望，不能解释为直接平均概率。第 18 页常用无权重噪声 MSE 与完整变分目标的权重、端点项有区别。[DDPM 原论文第 3 节](https://arxiv.org/html/2006.11239v2#S3)
